# 颜喵自带小游戏

六个游戏均为协议 1.0.0 的标准插件，源码和产物使用同一个受限宿主。前四款保留原型画风；扫雷、2048使用樱粉／梅紫卡片并适配系统明暗色，不注入主程序CSS。脚本置于 `ui/game.js`，遵守宿主CSP，不引入AI接口或联网请求。

## 源码与产物

- `rock-paper-scissors/`：`com.yanmew.game.rock-paper-scissors`，剪刀石头布。
- `dice/`：`com.yanmew.game.dice`，掷骰子比大小。
- `star-catcher/`：`com.yanmew.game.star-catcher`，接星星。
- `my-home/`：`com.yanmew.game.my-home`，我的家。
- `minesweeper/`：`com.yanmew.game.minesweeper`，扫雷。
- `2048/`：`com.yanmew.game.2048`，2048。
- `shared/runtime.js`：第一方存档、钱包请求去重与中断核对。构建时复制至每个包的 `ui/runtime.js`，每个 ZIP 都可独立安装，不依赖另一个插件。
- `shared/classic-runtime.js`、`shared/classic.css`：扫雷和2048的付费局、每日限次、棋盘恢复及响应式视觉，构建时仅复制到这两款游戏。

每个目录的 `manifest.json` 声明 `wallet.modify`；不申请联网权限，不额外声明设置。包路径由 `plugins/bundled-games.json` 列出。版本或存档结构变化按 SDK 的 SemVer 与迁移协议处理，不能修改已经发布的同版本包。

## 钱包及存档

所有游戏只使用颜喵全局喵币，不赠送原型中的初始余额。余额采用宿主十进制字符串与客户端 BigInt，不作为权威字段保存进私有存档。前三个游戏拒绝钱包可纯玩；我的家必须获得钱包授权，没有纯玩模式。熟练度是我的家私有成长值，与桌宠亲密度无关。

每个插件只使用 `state.main`：`{version:1, progress:{...}, pending:null|{request, after}}`。钱包操作先保存旧进度和完整请求，然后提交钱包，最后保存新进度并清除 pending。若中断后请求已有账单，沿用原请求 ID 与原运行 ID 核对并补存进度，不重复扣款；旧运行尚未提交的请求不重放。未知结果保留 pending 并禁止新操作，重新打开后恢复；明确余额不足或权限拒绝保留旧进度。

窗口打开到关闭是一条宿主运行，所有游戏可在同一个窗口持续游玩，不逐局调用 `game.complete()`。每日次数、玩法进度和最后一局结果由插件自己保存。前三个游戏各自每天 20 局，开始时落盘次数，纯玩和喵币模式共用次数；日期为电脑当前时区的 `YYYY-MM-DD`。游戏中和结算中锁定模式，不能通过关闭窗口规避已提交的费用或失败结算。

## 规则

- 扫雷：初级8×8／10雷，入场5币、通关10币；中级16×16／40雷，20币／40币；高级16×30／99雷，50币／100币。首击及相邻区域安全；右键依次旗帜、问号、空白，双击已翻数字按旗数展开，错误标旗可能踩雷。失败或放弃不退款、无奖励。
- 2048：赚钱局入场20币，结束时按最高数字一次结算：256→10、512→25、1024→50、2048及以上→200，不累加；低于256无奖励。可主动结束或无路可走自动结束，达到2048可继续挑战。
- 扫雷和2048分别每天最多5局赚钱局；免费局不限次且不扣币、不发币。开始扣费并保存次数，棋盘每步保存，重开恢复未完成局；拒绝权限、余额不足不占次数。额度归属插件私有存档，沿用现有插件数据清理规则，不是防篡改的线上竞赛额度。
- 剪刀石头布：开始前至少 4 币，胜 +5、负 -4、平 0。系统出拳使用 `game.random()`；先一次提交结果再播放原倒计时、手势和金币动画。
- 骰子：开始前至少 3 币，胜 +3、负 -3、平 0；玩家掷出 6 额外 +2。双方实际点数使用 `game.random()`，基础变化与幸运奖励合成一笔净额提交，仍按原顺序播放两段动画。平局掷出 6 得到 +2。
- 接星星：每局 20 秒，开始扣 8 币，完成时每接住一颗星星奖励 1 币。金色星星仍只计 1 分，外观区别沿用原型。未完成时关闭不退费、不补发得分；完成奖励已提交但存档未写完时重开核对。纯玩不扣费、不发币。
- 我的家：田地 50 币开启，作物生长 1 小时，升级 40/80 币，等级上限 120；钓鱼熟练度 30 解锁，低/高级塘 1/2 币，每天 20 次，鱼竿耐久 80、购买 30 币，鱼每 1000 克售 1 币；养殖场需 500 熟练度和 60 币，升级 60/120 币，上限 120。钓鱼改为互动鱼钩挑战：点按上抬、松开下落，在移动活动区内积攒进度；大鱼活动区更短，每次路线不同。抛竿后立即保存入场费、次数和耐久，放弃或关闭视为失败，不退本次消耗；成功只增加一次鱼获。种子、礼物、动物和升级熟练度条件保持原数值。作物使用绝对成熟时刻，关闭期间仍自然生长。
- 我的家的田地每日奖励、鸡蛋/牛奶每日收取属于插件私有规则；不创建或操作颜喵的全局签到，所有相关币变动只记录 `plugin_game` 账单。
- 菜品按原型已列出的价格出售：番茄炒蛋 20、蔬菜拼盘 28、牛奶炖蛋 12、红烧猪肉 18、炖牛肉 25。关闭确认弹窗会清理旧回调，宰杀确认重新检查动物库存；所有进度动作串行保存，成功后才公开库存及原动画。

游戏窗口默认800×600，可手动缩放。小窗口按需纵向滚动，不裁切操作按钮；扫雷高级棋盘自适应30列。共享窗口样式来自 `shared/window.css`，经典棋盘另用 `shared/classic.css`。当前源码包版本：2048 1.0.2、dice 1.0.3、minesweeper 1.0.2、my-home 1.0.4、rock-paper-scissors 1.0.3、star-catcher 1.0.3；存档封装均为1，升级保留进度。互动钓鱼等源码增量是否进入正式包，见[当前实现与版本范围](../../docs/当前实现与版本范围.md)。

## 构建及定向检查

```powershell
npm run plugins:build
node --test plugins/build/first-party.test.mjs
node --test plugins/build/classic-games.test.mjs
./scripts/copy-plugin-resources.ps1 -Destination <便携版目录>
```

构建生成 `resources/plugins/*.yanmew-game` 与清单，逐包使用 Rust 校验器验证。`tauri dev/build` 会先调用构建脚本；开发运行从项目资源读取，发布运行从 exe 旁的 `resources/plugins/` 读取。发布时同时复制 Embedding 资源。资源不是用户存档，不进入备份；正式数据仍由 SQLite 保存。

第一方游戏基础按钮反馈、键盘焦点和减少动态效果遵循共享window.css；存档、权限及玩法保持原规则。
