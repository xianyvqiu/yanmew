# 食品资源

六张透明 PNG，使用内置 image_gen 生成后等比归一到256×256。用于食品卡片和鼠标跟随，随前端构建打包；不属于API额度或现实货币。生成于2026-10-19。

文件为 `token.png`、`cloud_cake.png`、`black_tea.png`、`cat_cookie.png`、`rice.png`、`dried_fish.png`；复现说明见 [generation-prompts.json](generation-prompts.json)。Token免费无限，其余每份5喵币；价格和库存由Rust/SQLite负责，图片不承担记账。食物是独立素材，角色的咀嚼图中不画食物。
