# 颜喵 YanMew 0.1.0

Windows x64 便携版，支持 Windows 10/11。电脑需要 Microsoft Edge WebView2 Runtime；通常随系统或 Edge 安装，不需要 Node.js、Rust 或 Python。

## 启动与退出

1. 将整个 ZIP 解压到可写目录。不要直接从压缩包内启动，也不要只复制 exe。
2. 双击 `yanwenzi.exe`。首次启动会在同目录建立 `data/` 和默认“电子小猫”的教程会话。
3. 在“设置 → 提供商”填写自己的聊天服务地址、模型和 Key，测试后选择聊天当前项。没有聊天提供商时仍可打开设置并配置。
4. 桌宠底部聊天图标打开快捷输入；右上角“…”可打开聊天详情、设置，也可开启全屏游走。关闭聊天或设置窗口不会退出程序；完全退出可用托盘右键“退出”或设置中的退出入口。同一份data只运行一个实例，再次启动会唤出已有宠窗；不同数据目录可以独立运行。

## 随包内容

- 本地中文 Embedding 模型，用于记忆检索，无需单独下载。也可在提供商页配置自己的联网 Embedding 服务。
- 剪刀石头布、掷骰子、接星星、我的家、扫雷、2048六个小游戏，入口在“全局设置 → 小游戏插件”。首次使用可在插件管理决定钱包权限；“我的家”需要钱包授权。扫雷与2048分别每天最多5局赚钱局，免费局不限次、不扣币、不领奖。
- GPT、Claude、Gemini、DeepSeek 四位可选图片人设，各有初始图与三十张透明互动及情绪图，包含独立报错／超载表情，在“设置 → 人设”切换，可编辑、删除；无需生图 Key，角色名不绑定同名模型。
- 食物商城与仓库：Token基础食物免费无限，其余五种食物每份5喵币；选取后点击桌宠投喂，右键或Esc取消。Skill仓库可保存提示词资料并绑定人设。
- 全屏游走默认关闭，开关重启保留；拖到上缘、左右边缘或任务栏上沿可停靠，拖离边缘解除。停靠与游走均适用于颜文字和图片模式。
- 内置离线日历和许可声明。
- 程序所需微软 C++ 运行 DLL。请保留 exe 旁的 DLL 及整个 `resources/` 目录。

聊天、搜索、天气兜底和生图按各自设置使用用户提供商。搜索和生图默认关闭，其服务额度与喵币独立。语音和 Android 不包含在当前版本中。

默认在家有效等待4～8小时后再次出门，出门前暂停时保留进度；每次旅行默认1～3小时，返回按实际时钟自动处理。图片人设上传初始图后可选择批量生成表情预览或自行逐项上传；生图使用用户自己的服务，可能消耗服务额度。

## 数据与迁移

数据保存在 exe 旁的 `data/`。发布包不含预先填写的 Key、聊天或存档。更换电脑时使用设置中的备份导出/导入，服务密钥需要在新电脑重新填写。

升级前先退出程序并备份数据。保留旧版 `data/`，替换程序及随包资源即可；首次启动会按数据库版本执行必要迁移。不要用空目录覆盖或删除原 `data/`。

主程序许可证见 `LICENSE`；第三方声明见 `THIRD_PARTY_NOTICES.md`、`licenses/` 及资源目录中的许可文件。

## 当前交互说明

喵币账单主页显示余额和账单入口。现实记账主页显示月度收支、三种可直接编辑的预算及近期账单；底部导航在各记账子页保留，用于切换明细、统计、资产等；筛选点击展开。日历按月份方向左右滑入，加载时保留旧月份，系统减少动态效果时直接切换。

拖动桌宠超过阈值后使用拎起表情，颜文字与图片模式均适用；松手恢复。快速向上或斜上抛出时按速度飞行，撞边反弹、落地后切换底部停靠；可在空中接住。出行期间暂停这些互动。

出行时显示累计出门时分；邮箱为单列摘要卡，可原位展开/收起完整信件。回信在寄信成功时随机抽取延迟（默认10–30分钟），后台到期生成，不依赖点击。途中主动信与针对用户信的回信独立，旅行结束会取消未完成的回信。

出行期间左键点击桌宠可查看已经出门的时间，普通互动暂停；邮箱卡片可查看信件所属出行。


## 生图与参考形象

生图用途支持硅基流动、通用OpenAI兼容接口，以及已适配的Gemini原生、百炼Qwen同步、火山方舟/BytePlus和OpenRouter图片接口。提供商页可展开查看官方地址和使用说明；请求不按模型名称提前拦截，服务实际返回失败后才提示原因。测试连接不实际生成图片，也不代表模型已通过参考图能力验证。

普通聊天可请AI按需携带当前人设已接受的默认形象作为参考，绘图允许背景。纯文字生图不要求参考能力；参考图不兼容时会说明原因，不自动去掉参考图、换模型或付费重试。表情生成使用当前人设和真实默认参考图，每张卡片原位显示进度、失败原因及待接受预览。

表情、饰品和伴手礼需透明背景：先检测结果，不透明时才尝试随包的本地U²-Net抠图，不能处理时保留已有资料并提示失败。普通聊天图片不强制透明，用户可另外要求检测或抠图。生图和独立识图可能消耗你配置服务的额度。

首次教程以实际页面为主体，通过短提示介绍入口；可以跳过，之后不会反复自动出现，也能从用户手册重看。教程期间只介绍连接位置，不要求填写模型配置。
