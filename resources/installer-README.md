# 颜喵安装版使用说明

双击安装包，按中文向导选择目录并安装。默认安装给当前Windows用户，可选择创建桌面快捷方式；以后点击桌面或开始菜单中的“颜喵 YanMew”即可运行。首次配置聊天服务请进入“设置 → 提供商”。开机自启需要在软件内自行开启。

程序、模型与自带小游戏在安装目录；个人数据在当前用户的`%LOCALAPPDATA%\YanMew\data`。便携版数据仍在便携程序旁，两种版本的数据不会自动合并，迁移可使用现有备份导入。

升级或重新安装会保留个人数据。安装和卸载前请先通过托盘“退出”或设置中的退出入口正常退出程序。

在Windows“已安装的应用”或开始菜单中可以卸载颜喵。**主动卸载会永久删除该安装版的全部聊天、人设、记忆、设置、喵币、密钥、图片、插件和游戏存档，不保留数据。** 需要保留的内容请提前导出备份；保存在其他位置的备份不会删除。

本地Embedding、四个小游戏和C++运行DLL随包提供，不需要Node.js、Rust或Python。WebView2缺失时安装向导需要联网补装。语音和Android不包含在首版中。
