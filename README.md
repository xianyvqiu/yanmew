# 颜喵 YanMew

**住在桌面上的 AI 小伙伴，记得聊天，也拥有自己的日常。**

从一只颜文字小猫开始，陪它聊天、旅行、收集小礼物，或换成你喜欢的透明图片形象。

Windows 桌宠 · 多人设 · 长期记忆 · 图片创作 · 小游戏

[开始使用](#开始使用) · [功能一览](#功能一览) · [数据与备份](#数据与备份) · [本地开发](#本地开发) · [项目文档](#项目文档)

</div>

---

颜喵是一款 Windows 桌面陪伴应用。你可以在透明宠窗直接聊天，也可以打开聊天详情，管理会话、查看记忆，让不同人设拥有各自的形象和经历。

**模型服务由你选择，数据保存在本机。** 应用不附带聊天 API Key；聊天、识图、生图等能力使用你配置的服务。本地自带的 Embedding 模型用于检索记忆，不是离线聊天模型。

> **当前状态：开发与实机测试阶段。** 下方介绍的是当前源码已接入的功能，下载包是否包含最新改动请以对应发布说明为准。真实模型兼容性、邮件投递、透明窗口和多屏体验仍需实机验证。当前支持 Windows 10/11 x64；Android、语音交互及 GPT-SoVITS 声线导入属于后续规划。

## 功能一览

### 🐾 颜文字小猫，也可以是图片伙伴

- **透明宠窗**：置顶、拖动、隐藏与恢复，记住窗口位置；亮暗主题下使用描边按钮，尽量少遮挡桌面。
- **日常互动**：点击、摸摸、喂食，伴随饥饿、待机、无聊、睡眠与出行状态，亲密度最高 999。
- **可调的生活节奏**：默认 10 分钟无互动进入待机；无聊与睡觉共用默认 45 分钟触发时间，到点随机选择。可在“时间与桌宠”中调整。
- **图片自定义创作**：按人设上传透明 PNG/WebP，建立表情库并填写使用说明；也可批量填写生成要求，逐张预览、重新生成和接受。
- **饰品与装扮**：制作、佩戴、出售饰品，调整相对桌宠的位置和大小；未开启生图或生图失败时，可用图标、Emoji、颜文字、符号组合兜底。

默认“电子小猫”之外，还内置四位可编辑、可删除的图片人设，每位带有初始图及八张透明基础互动图：

预置形象不需要生图 Key。**人设名称不绑定同名模型服务**，你可以自由搭配；编辑或删除后，重启不会自动还原。

### 💬 两个聊天入口，同一份会话

- 宠窗底部输入，回复在头顶气泡中流式显示；聊天详情提供完整记录与可收起的会话侧栏。
- 会话支持重命名、置顶、删除和绑定用户设定；人设的初始设定与当前设定可分别编辑。
- 支持中断、重说，以及达到输出长度限制后的主动“继续生成”。
- AI 回复支持 Markdown 标题、强调、列表、引用、代码块和表格；需要原样显示的内容可用 `<plain>…</plain>` 保留符号与换行；复制时去掉该包装标签。
- 上传图片让 AI 理解内容；配置搜索后，AI 可在普通聊天中按需搜索、读取公开网页。
- 按人设保存聊天背景、默认／透明／描边／毛玻璃气泡和双方文字颜色。

### 📖 记住经历，而不只是堆积聊天记录

完整对话结束后，后台生成短期记忆，再按规则整合为带标题、可追溯来源的长期记忆。聊天结合全文与向量检索查找相关往事，用户可查看、编辑和管理记忆。

另有独立记事本供 AI 按需记录、用户直接编辑。开启人设自调后，AI 可在必要时小幅调整当前设定；差异视图用红绿颜色和新增／删除标记展示变化。

聊天、记忆与记事本按会话保存。上下文不足时，会提示并减少**本次请求**携带的较旧内容，不因此删除历史。

### ✉️ 旅行、提醒与日常

- **出行与来信**：旅行途中寄信，返回时带来伴手礼与游记；删除游记不影响同次出行的信件和礼物。
- **提醒事项**：一次性或循环提醒，到点自动显示宠窗；气泡保留到点击“完成”或“收起”。
- **邮件提醒**：通过 SMTP 同时发送邮件，支持验证码绑定、失败状态查看与重试；关闭应用期间无法实时发信，重开后汇总过期事项。
- **时间与天气**：打开页面刷新天气，展示与昼夜联动的天气卡片；日历包含公历、农历、节日及全局自定义日期。
- **签到与喵币**：每日签到，节日有特殊祝福和奖励；饰品与小游戏共用全局钱包，可查看账单。

### 🎮 四个自带小游戏与本地插件

内置 **剪刀石头布、掷骰子比大小、接星星、我的家**，统一在“设置 → 小游戏插件”中打开和管理。

支持安装本地 `.yanmew-game` 包，查看插件详情、停用、卸载或清除数据并重载。自带游戏不可卸载。“清除数据并重载”重置存档、自有设置和授权，保留全局余额及已发生的账单。

小游戏可申请喵币或联网权限，由用户确认；玩法、局数限制和进度由插件自行管理。当前通过本地安装包扩展，不提供内置在线插件商店。

想制作小游戏？查看 [插件 SDK](plugins/sdk/README.md)、[插件模板](plugins/template/) 和 [自带小游戏说明](plugins/first-party/README.md)。

## 开始使用

### 1. 安装或解压

前往 [GitHub Releases](https://github.com/xianyvqiu/yanmew/releases)，以页面实际提供的附件为准；没有发布附件时，可按下方说明从源码构建。

- **安装版**：运行 `YanMew-版本号-setup.exe`，按中文向导安装，可创建桌面快捷方式。缺少 WebView2 时，安装器需要联网补装。
- **便携版**：完整解压 ZIP 到可写目录，双击 `yanwenzi.exe`。不要直接在压缩包中运行，也不要只复制 EXE；旁边的 DLL 和 `resources/` 都需要保留。

普通使用无需安装 Node.js、Rust 或 Python。便携版需要系统已安装 WebView2 Runtime。

首次启动会创建默认“电子小猫”和带一条产品介绍的初始会话。四位图片人设也会加入列表；已有用户首次使用包含这些资源的新版时，会保留原来的当前人设与历史。

### 2. 配置聊天

1. 宠窗右上角 **`…` → 设置 → 提供商**，添加连接名称、Base URL 和自己的 API Key。
2. 在聊天用途配置中选择连接、填写模型名并保存，测试连接。
3. 点击宠窗底部聊天图标开始输入，或通过 **`…` → 聊天详情** 打开完整聊天界面。

通用连接可供**聊天、记忆、识图、生图**复用，各用途单独选择模型。记忆和识图可以跟随聊天；单独配置识图时，先由识图模型理解图片，再交给聊天模型回答。对应服务仍需支持所选用途的接口与能力，填写模型名称不会自动赋予它识图或生图能力。

最大输出默认 **32768 tokens**，可以在高级配置中调整；实际生效值还受服务商限制。

### 3. 按需配置可选能力

- **记忆检索**：完整分发包自带本地 `BAAI/bge-small-zh-v1.5`。也可在独立的 Embedding 配置中选择联网服务；本地模型不可用时退回全文检索，不自动上传记忆。
- **联网搜索**：默认关闭。支持 **Tavily、博查、自定义 Tavily 兼容接口**，填入自己的 Key 后开启。网页读取能否成功取决于站点和服务，不保证能打开登录页或所有网页。
- **生图与图片创作**：配置并开启生图用途。参考初始形象生成表情需要服务支持 OpenAI-compatible 的图像编辑接口；图片必须有真实透明背景，先预览再接受。手动上传不需要生图服务。
- **图片模式**：“设置 → 人设”切换预置伙伴，或在“桌宠自定义创作”中为当前人设建立图片库；新开启时需要已接受的初始图及待机图。
- **邮件提醒**：“设置 → 通用”分别填写发信邮箱、收信邮箱，按页面引导获取 SMTP 授权码并完成验证码验证。常见邮箱会预填服务器配置。

联网请求的额度与费用由对应服务商计算，与游戏中的喵币无关。

## 数据与备份

**本地保存不等于所有功能离线。** 聊天、记忆生成和识图会将所需内容发送给所选模型服务；生图、搜索、天气和邮件按各自配置联网。本地 Embedding 在本机处理检索，不需要上传记忆。

- **便携版数据**：EXE 同目录的 `data/`，数据库为 `data/yanwenzi.db`。
- **安装版数据**：`%LOCALAPPDATA%\YanMew\data`，与便携版分开，不自动合并。
- **密钥**：API Key、SMTP 授权码通过 Windows DPAPI 加密保存，不随备份导出；换电脑后重新配置。
- **导出**：通用设置支持全量、人设、会话、用户设定及小游戏插件使用数据等范围。随包模型、可重建索引和小游戏程序包不进入数据备份。
- **导入**：部分资料按预览关联人设并追加会话；小游戏数据不重放历史喵币变化，权限需要重新确认。

> **全量恢复会替换全局设置、钱包与账单等数据。** 它与普通资料追加不同，确认前请阅读预览并备份当前内容。

升级或移动便携版前，请完全退出并保留原 `data/`。安装版升级保留个人数据；**主动卸载安装版会删除该安装版的全部个人数据**，需要保留的内容请先导出。

## 常见问题

<details>
<summary><strong>关闭聊天窗口，为什么宠物还在？怎么完全退出？</strong></summary>

关闭聊天详情、设置窗口或隐藏宠窗不等于退出。在系统托盘图标右键选择“退出”，或使用通用设置中的退出入口。

</details>

<details>
<summary><strong>能完全离线聊天吗？</strong></summary>

应用不附带本地聊天模型。内置 Embedding 只用于记忆检索；聊天需要你配置可访问的模型服务。提醒、资料管理和小游戏等不需要每次都调用聊天模型。

</details>

<details>
<summary><strong>为什么选了图片人设，却不能生成新表情？</strong></summary>

预置形象可以直接使用；生成新表情还需要开启生图用途，并选择支持参考图编辑和透明图片输出的服务。应用不会自动抠图，也不会把不透明图片当作合格结果保存。

</details>

<details>
<summary><strong>为什么提醒没有立即发到邮箱？</strong></summary>

请确认已经绑定收信邮箱并开启邮件提醒，应用正在运行，SMTP 配置有效。关闭应用期间不能实时发送，重新打开后会汇总过期事项；发送失败可在通用设置查看原因。

</details>

## 本地开发

### 环境与启动

在 Windows 上准备 **Node.js 20+、npm、Rust stable（MSVC）、Visual Studio C++ 构建工具及 WebView2 Runtime**。在项目根目录执行：

```powershell
npm ci
npm run tauri dev
```

`tauri dev` 会构建自带小游戏、启动前端服务和桌面应用；`npm run dev` 只启动前端，不能代替完整桌面环境。本地 Embedding 资源的准备和校验见 [资源说明](resources/README.md)。

### 构建

```powershell
# 编译 release 程序，不组装完整分发包
npm run tauri build -- --no-bundle

# 构建并组装完整便携版：程序、模型、小游戏、运行库和许可证
./scripts/build-portable.ps1

# 构建安装向导与卸载程序
./scripts/build-installer.ps1
```

发布产物写入 `releases/构建时间/`，包含完整程序目录、分发包与 SHA-256 校验文件。刚成功编译过 release 时，两个打包脚本均可加 `-SkipBuild` 复用编译结果；打包前须准备好资源说明中列出的文件，并退出正在使用的旧程序。

安装包使用中文 NSIS 向导，可选择安装目录与桌面快捷方式；具体构建条件、安装和卸载规则见 [安装与发布设计](docs/安装与发布设计.md)。

### 技术与目录

**Tauri 2 + Rust** 承载桌面与业务服务，**React 18 + TypeScript + Vite** 构建界面，**SQLite** 持久化数据，**FTS5 + Embedding** 支持混合记忆检索。本地 Embedding 使用 ONNX Runtime，在 CPU 上运行，无需 Python 或 CUDA。

```text
src/          React 页面、组件、状态与桌面接口
src-tauri/    Rust 业务、模型服务、调度与平台适配
plugins/      小游戏 SDK、模板、第一方游戏与打包工具
db/           SQLite schema、迁移与结构检查
docs/         正式设计、接口与验收文档
resources/    随包模型、图片人设、小游戏、日历及许可声明
scripts/      可复用的构建与资源准备工具
```

本地的 `my_doc/` 仅放开发过程记录与附件，`releases/` 放发布产物，`.test-temp/` 放临时测试与资源转换材料；三者均由 Git 忽略，不作为正式文档或源码依赖。
