## 关于颜喵

颜喵是一款以陪伴和日常互动为主的 Windows 桌面应用。它可以安静地待在桌面一角，也可以陪你聊天、记下事情、在出门旅行时寄来信件。

你可以保留轻巧的颜文字形象，也可以为不同人设上传透明图片、建立表情库。聊天使用你自己配置的 AI 提供商，聊天记录、记忆和养成数据保存在本机。

> **当前处于开发与实机测试阶段。** 主要功能已接入，真实模型服务、邮件收件、多屏与不同缩放下的体验仍在持续验证。当前面向 Windows 10/11 x64；语音和 Android 属于后续扩展。

## 功能介绍

### 🐾 桌面上的小伙伴

- **透明桌宠**：窗口置顶、拖动、隐藏与恢复，记住上次的位置。
- **两种形象**：默认使用颜文字，也可按人设开启图片模式，上传透明形象与互动表情。
- **自定义创作**：填写动作或表情要求，调用配置好的生图服务批量生成，预览后选择保存，支持逐张重新生成。
- **日常互动**：点击、摸摸、喂食，默认10分钟无互动后显示待机姿态，45分钟随机进入无聊或睡觉，均可在设置调整；陪它经历饥饿和旅行；亲密度最高为 999。
- **饰品佩戴**：收集和制作饰品，拖动调整相对桌宠的位置与大小。没有生图配置或生成失败时，制作饰品可使用图标、Emoji、颜文字或符号组合作为外观。

### 💬 聊天，也慢慢熟悉彼此

- **多个人设与会话**：分别管理初始设定、当前设定和表情库；会话可重命名、置顶、删除，绑定不同用户设定。
- **两个聊天入口**：在宠窗快捷输入、看头顶气泡流式回复，或打开聊天详情查看完整记录；共用同一份会话数据。
- **可控的生成**：支持流式输出、中断、重说，以及达到长度限制后主动继续生成。
- **按需看图与搜索**：聊天可添加图片；配置搜索后，AI 可在正常聊天中按需查询网页。搜索支持 Tavily、博查与 Tavily 兼容的自定义服务。
- **聊天外观**：亮暗主题、自定义背景、默认 / 透明 / 描边 / 毛玻璃气泡，以及双方文字颜色，按人设保存。

### 📖 留下共同的经历

- **短期与长期记忆**：完整对话后在后台生成短期记忆，按规则整合为带标题、可追溯来源的长期记忆。
- **混合回忆**：全文检索与向量检索共同查找相关往事，需要时再打开记忆来源和原始回合。
- **独立记事本**：AI 可以按需记录，你也可以直接查看与编辑。
- **渐进的人设调整**：开启后，AI 可在必要时小幅调整当前设定；通过红绿差异及新增、删除标记查看相对初始设定的变化。

聊天、记忆和记事本按会话保存。历史可以持续积累，每次回复按需检索；上下文不足时减少本次携带的旧内容，不因此删除历史记录。

### ✉️ 旅行、提醒与日常小事

- **旅行与来信**：桌宠出门后可以写信，返回时带回伴手礼和旅行游记；出行、信件、游记与礼物关联保存。
- **提醒事项**：支持一次性和循环提醒，到点展示提醒气泡；重新打开应用后汇总离开期间的过期事项。
- **邮件提醒**：分别填写发信与收信邮箱，按引导配置 SMTP 授权码并通过验证码绑定。应用运行时可同时发邮件，关闭期间的过期事项在重开后汇总发送。
- **时间与天气**：查看天气信息，卡片随白天和夜晚变化；日历显示公历、农历、节日和自定义纪念日。
- **喵币与签到**：每日签到、节日祝福、饰品与小游戏共用全局喵币钱包，变化记录在账单中。

### 🎮 自带小游戏，也支持扩展

内置 **剪刀石头布、掷骰子比大小、接星星、我的家** 四个小游戏，它们也以标准小游戏插件运行。

在“设置 → 小游戏插件”中统一打开游戏、安装本地 `.yanmew-game` 包、管理权限和存档。第三方小游戏可申请喵币与联网权限，由用户决定是否允许；插件自己的游戏进度与玩法限制由插件管理。

自带小游戏可停用或清除数据，不能卸载。“清除数据并重载”会重置插件存档、自有设置及授权，保留已经发生的账单与全局余额。小游戏使用各自的界面风格。

开发自己的小游戏可阅读 [插件 SDK](plugins/sdk/README.md)、[插件模板](plugins/template/) 和 [自带小游戏说明](plugins/first-party/README.md)。

## 快速开始

### 1. 启动程序

使用完整的 **Windows x64 便携包**：将 ZIP 全部解压到可写目录，然后双击 `yanwenzi.exe`。请保留旁边的 DLL 和 `resources/`，不要只复制 EXE，也不要直接在压缩包中运行。

运行需要 **Windows 10/11 和 WebView2 Runtime**，不需要安装 Node.js、Rust 或 Python。首次启动会创建默认“电子小猫”人设及一条介绍产品的教程会话。

发布包以 [GitHub Releases](https://github.com/xianyvqiu/yanmew/releases) 中实际提供的附件为准；尚未提供发布附件时，可按下方步骤从源码构建。

### 2. 配置聊天模型

1. 点击宠窗右上角 **`…` → 设置 → 提供商**，添加连接名称、Base URL 和自己的 API Key。
2. 在 **模型用途 → 聊天** 中选择该连接，填写模型名并保存，再测试连接。
3. 回到宠窗，点击底部聊天图标，或通过 **`…` → 聊天详情** 开始对话。

提供商连接可以复用：聊天、记忆、生图和识图分别选择连接与模型，一个连接或模型也可以用于多个用途。记忆与识图可跟随聊天；独立配置识图时，由识图模型先理解图片，再交给聊天模型回答。

### 3. 按需要开启其他能力

- **记忆检索**：默认使用随便携包提供的本地 `BAAI/bge-small-zh-v1.5`，也可单独配置联网 Embedding 服务。它用于检索记忆，不是本地聊天模型。
- **联网搜索与生图**：默认关闭，在提供商页配置并开启；调用额度与费用由相应服务商计算，与喵币无关。
- **图片桌宠**：在设置的“桌宠自定义创作”中为当前人设启用，上传初始形象与待机等表情，或使用生图服务生成；初始图和待机图接受后可开启。
- **邮件提醒**：在通用设置中配置发信、收信邮箱并完成验证。

隐藏宠窗、关闭聊天详情或设置窗口都不会退出应用。要完全退出，请在系统托盘图标的右键菜单中选择 **退出**，或使用通用设置中的退出入口。

## 数据与隐私

**数据保存在本机；使用联网能力时，必要内容会发送给你所配置的服务。** 聊天与记忆生成通常需要模型 API；本地 Embedding 不需要上传记忆，但它不代表整个 AI 聊天都在离线运行。识图、生图、搜索、天气与邮件按各自配置访问相应服务。

- **便携版**：数据位于 EXE 同目录的 `data/`，数据库为 `data/yanwenzi.db`。
- **安装版**：数据位于 `%LOCALAPPDATA%\YanMew\data`，与便携版数据分开。
- **密钥保护**：API Key、SMTP 授权码等凭据使用 Windows DPAPI 加密，不随备份导出；换电脑后需要重新配置。
- **备份与迁移**：通用设置支持全量、人设、会话、用户设定及小游戏插件使用数据等备份范围。模型、可重建检索索引和小游戏程序包不进入数据备份。
- **小游戏数据导入**：恢复设置和存档，不导入插件账单，不重放历史喵币变化；钱包和联网授权需要重新确认。备份会保留已有的插件来源链接，方便重新寻找安装包。

升级或移动便携版前，先完全退出并备份，保留完整程序目录及原 `data/`。安装版升级保留数据，**主动卸载安装版会删除该安装版的全部个人数据**，需要的内容请先导出。

全量导入会替换全局设置、钱包与账单等数据；部分资料导入按预览确认关联、追加会话。操作前请查看导入预览，不要将全量恢复当作普通资料追加。

## 本地开发

### 环境与启动

在 Windows 上准备 **Node.js 20+、npm、Rust stable（MSVC）、Visual Studio C++ 构建工具及 WebView2 Runtime**。在项目根目录执行：

```powershell
npm ci
npm run tauri dev
```

`tauri dev` 会构建自带小游戏、启动前端服务和桌面应用；`npm run dev` 只启动前端，不能代替完整桌面环境。本地 Embedding 资源的准备和校验见 [资源说明](resources/README.md)。

### 构建

```powershell
# 编译 release 程序，不组装完整分发包
npm run tauri build -- --no-bundle

# 构建并组装完整便携版：程序、模型、小游戏、运行库和许可证
./scripts/build-portable.ps1

# 构建安装向导与卸载程序
./scripts/build-installer.ps1
```

发布产物写入 `releases/构建时间/`，包含完整程序目录、分发包与 SHA-256 校验文件。刚成功编译过 release 时，两个打包脚本均可加 `-SkipBuild` 复用编译结果；打包前须准备好资源说明中列出的文件，并退出正在使用的旧程序。

安装包使用中文 NSIS 向导，可选择安装目录与桌面快捷方式；具体构建条件、安装和卸载规则见 [安装与发布设计](docs/安装与发布设计.md)。

### 技术与目录

**Tauri 2 + Rust** 承载桌面与业务服务，**React 18 + TypeScript + Vite** 构建界面，**SQLite** 持久化数据，**FTS5 + Embedding** 支持混合记忆检索。本地 Embedding 使用 ONNX Runtime，在 CPU 上运行，无需 Python 或 CUDA。

```text
src/          React 页面、组件、状态与桌面接口
src-tauri/    Rust 业务、模型服务、调度与平台适配
plugins/      小游戏 SDK、模板、第一方游戏与打包工具
db/           SQLite schema、迁移与结构检查
docs/         正式设计、接口与验收文档
resources/    随包模型、小游戏、日历及许可声明
scripts/      可复用的构建与资源准备工具
```

本地的 `my_doc/` 仅放开发过程记录与附件，`releases/` 放发布产物，`.test-temp/` 放临时测试与资源转换材料；三者均由 Git 忽略，不作为正式文档或源码依赖。
