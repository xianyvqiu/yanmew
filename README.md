## 启动与关闭（当前开发版）

所有命令都在本 README 和 `package.json` 所在的项目根目录执行。

### 直接运行已构建的测试版

在资源管理器中打开本目录下的 `src-tauri\target\debug\yanwenzi.exe`，双击启动。也可以在 PowerShell 中执行：

```powershell
Set-Location "C:\my_program\my_idea\yanwenzi"
.\src-tauri\target\debug\yanwenzi.exe
```

测试版无需启动 Vite。调试版本可能带有控制台窗口；尚未构建时，先执行下面的测试版构建命令。每次只启动一个实例，避免出现多个宠窗和托盘图标。

### 开发模式

首次安装依赖后启动：

```powershell
npm install
npm run tauri dev
```

开发模式会同时启动前端开发服务和桌面程序。`npm run dev` 只启动前端服务，不会打开完整桌面应用。

### 隐藏、恢复和退出

- 点击宠窗的“隐藏宠窗”只会收起颜文字，留下“显示宠窗”按钮，应用仍在运行。
- 点击“显示宠窗”按钮，或左击系统托盘图标，可以恢复宠窗。
- 完全关闭应用：在 Windows 任务栏右下角找到本应用的托盘图标，右键选择“退出”。图标可能位于向上箭头展开的隐藏图标区。
- 开发模式结束时，在运行 `npm run tauri dev` 的终端按 `Ctrl+C` 停止开发命令；如果前端服务仍在运行，也在对应终端按 `Ctrl+C`。
- 点击宠窗“聊天”可管理会话、发送消息、查看流式回复并暂停；点击“设置”或托盘设置可修改主题并管理提供商、人设、提醒及天气配置。重复打开聚焦已有窗口，关闭聊天/设置窗不退出应用。首版设置页均已接通。已有当前会话时可点击互动，右键选择喂食或摸摸；饰品、签到、旅行等玩法均可进入对应页面。通用页可查看实际版本与退出应用。

重新构建前先退出旧程序，否则 Windows 可能因可执行文件被占用而拒绝替换。

## 构建

构建本地测试版：

```powershell
npm run tauri build -- --debug --no-bundle
```

产物：`src-tauri/target/debug/yanwenzi.exe`。

构建 release 可执行文件：

```powershell
npm run tauri build -- --no-bundle
```

产物：`src-tauri/target/release/yanwenzi.exe`，实际路径以构建输出为准。不能只复制此文件作为完整便携版。

构建并组装完整 Windows x64 便携版：

```powershell
./scripts/build-portable.ps1
```

若刚刚成功执行过上面的 release 构建，可使用 `./scripts/build-portable.ps1 -SkipBuild` 仅组装资源。脚本复用三个资源复制脚本，加入本地 Embedding 模型、四个小游戏及清单、微软 C++ 运行 DLL、许可证和使用说明，再生成 ZIP 与 SHA-256 文件。构建机器需有 Node.js、Rust 和包含 x64 Redistributable CRT 的 MSVC 开发工具；运行便携版无需这些开发工具，但需要 WebView2 Runtime。

产物放在本项目 `my_doc/releases/构建时间/` 下：`YanMew-0.1.0-windows-x64/` 为完整程序目录，`颜喵 YanMew-portable.zip` 为分发包。每次使用新目录，不覆盖旧发布包。解压后双击 `yanwenzi.exe`；保留 exe 旁的 DLL 和 `resources/`，首次运行自行建立 `data/`。发布包不包含开发者的数据库、密钥、聊天和个人存档。生成包之后的干净目录启动、真实服务和原生交互验收分别记录，不能仅凭构建成功视为全部通过。
