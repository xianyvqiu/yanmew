## 完整产品规划

天气与定位后端已接入 Windows 定位、Open-Meteo 查询、和风兜底、可取消超时及带来源/观测时间的缓存。“设置 → 时间与天气”已开放主动刷新、取消、缓存状态查看与可选和风配置。打开页面不会自动请求定位；Host 保存于 SQLite，密钥使用 DPAPI，输入留空保留原密钥，清除需明确操作。聊天已注入带时效和来源的环境缓存，不自动定位或联网刷新，真实定位授权与在线天气仍需实机验收。

提醒后端已实现一次性及日/周/月规则管理、在线触发记录、启动离线补偿、展示确认和本次状态管理。循环规则跟随电脑当前时区，跳过不存在时刻，重复时刻只触发第一次；数据先保存到 SQLite，再通知界面。聊天创建提醒已接入同一聊天工具循环，复用参数校验、事务保存和变更通知，不额外调用一次模型提取。提醒管理页面已接入规则新增/编辑/删除、触发记录状态管理、分页查询和页面内离线汇总确认。宠窗已接入到点提醒气泡与启动离线汇总：新提醒自动恢复隐藏宠窗，气泡保留到完成或收起，可直接进入提醒管理。展示确认与完成状态独立保存。当前使用固定默认文案，AI 润色仍待后续接入。

- 透明置顶的颜文字桌宠窗口，支持拖动、隐藏/显示、位置记忆。
- 主程序内置亮色与暗色两套主题，可选择跟随 Windows、固定亮色或固定暗色；主题即时作用于主程序窗口，小游戏插件保持各自视觉。
- 多 API 提供商配置：聊天和记忆整合可分别选择 provider；Embedding 默认使用随便携版打包的 `BAAI/bge-small-zh-v1.5` 本地模型，也可切换到用户配置的联网 OpenAI-compatible Embedding API。
- 多 AI 人设：可切换当前人设、保存初始设定、开启/关闭人设自调，并用红绿颜色及“新增/删除”标记查看当前人设相对初始设定的累计差异；桌宠本体颜色和聊天窗背景按人设绑定。
- 分类表情库：点击（开心/惊讶/害羞）、饿、吃东西、困、无聊、思考；聊天回复时由 AI 实时生成表情。
- 流式聊天：AI 说话前先切换表情，支持暂停/中断；会话和聊天记录在聊天窗内管理。
- 会话级记忆与记事本：一轮完整对话对应一条永久保留的短期记忆；长期记忆带简短标题、明确来源与触发回合，支持精确回退、AI 重新整合、SQLite 全文检索与 Embedding 混合 RAG。
- 提醒系统：一次性、每天/每周/每月重复，支持手动编辑和状态管理。
- 天气与定位：Open-Meteo 优先，和风天气免费版兜底。
- 养成系统：亲密度、喵币、每日签到与节日彩蛋、饰品制作/佩戴/卸载/卖出；小游戏从第一版使用统一插件协议，石头剪刀布作为第一方插件随便携版提供，并支持从本地插件包安装其他小游戏。插件及其设置、授权、存档和游戏局均为应用全局数据；插件可申请按 HTTPS 来源授权的受限联网权限。
- 出行记录：统一保存目的地、活动时间线和实际礼物快照，信件、游记与礼物共用事实；删除单个展示项不抹除出行事实。
- 旅行系统：当前会话在家空闲时递减一次抽取并持久化的出行倒计时，默认范围为 2–4 小时有效在线时间；旅行期间写信与回信，正常返回带回伴手礼并生成会话级旅行游记；切换会话会暂停未出发倒计时，已开始的旅行与待回信则取消。
- 节日彩蛋：内置节日母表 + 会话级节日子表，农历与节气日期每年查内置表自动更新；命中节日固定发放 10 喵币并展示该节日的祝福词，全程离线、不依赖日历接口。
- 睡眠：默认无互动 45 分钟后随机进入无聊或睡眠，触发时间允许在设置修改；每次睡眠持续时间默认 60–120 分钟。
- 上下文超限：自动减少本次携带的较旧内容并提示，历史消息与记忆仍完整保留。
- 桌宠活动：无聊时按概率主动发消息，并在固定宠窗画布内移动颜文字、偶尔靠近画布内的鼠标位置；拖动、点击、聊天、睡觉、出门中或隐藏宠窗时暂停。
- 错误处理：无 Token 或主流程连接失败时进入休眠状态，红色感叹号显示中文错误。
- 导入导出：全量备份、人设资料包、人设完整包、会话包、用户设定包、插件使用数据包；API Key 不导出。插件使用数据包只恢复插件设置和存档，不包含插件程序包、游戏局、账单或钱包余额，导入后钱包与联网权限均待用户重新确认。

## 启动与关闭（当前开发版）

所有命令都在本 README 和 `package.json` 所在的项目根目录执行。

### 直接运行已构建的测试版

在资源管理器中打开本目录下的 `src-tauri\target\debug\yanwenzi.exe`，双击启动。也可以在 PowerShell 中执行：

```powershell
Set-Location "C:\my_program\my_idea\yanwenzi"
.\src-tauri\target\debug\yanwenzi.exe
```

测试版无需启动 Vite。调试版本可能带有控制台窗口；尚未构建时，先执行下面的测试版构建命令。每次只启动一个实例，避免出现多个宠窗和托盘图标。

### 开发模式

首次安装依赖后启动：

```powershell
npm install
npm run tauri dev
```

开发模式会同时启动前端开发服务和桌面程序。`npm run dev` 只启动前端服务，不会打开完整桌面应用。

### 隐藏、恢复和退出

- 点击宠窗的“隐藏宠窗”只会收起颜文字，留下“显示宠窗”按钮，应用仍在运行。
- 点击“显示宠窗”按钮，或左击系统托盘图标，可以恢复宠窗。
- 完全关闭应用：在 Windows 任务栏右下角找到本应用的托盘图标，右键选择“退出”。图标可能位于向上箭头展开的隐藏图标区。
- 开发模式结束时，在运行 `npm run tauri dev` 的终端按 `Ctrl+C` 停止开发命令；如果前端服务仍在运行，也在对应终端按 `Ctrl+C`。
- 点击宠窗“聊天”可管理会话、发送消息、查看流式回复并暂停；点击“设置”或托盘设置可修改主题并管理提供商、人设、提醒及天气配置。重复打开聚焦已有窗口，关闭聊天/设置窗不退出应用。其他设置表单按后续阶段开放。已有当前会话时可点击互动，右键选择喂食或摸摸；饰品、签到、旅行等玩法仍待实现。

重新构建前先退出旧程序，否则 Windows 可能因可执行文件被占用而拒绝替换。

## 构建

构建本地测试版：

```powershell
npm run tauri build -- --debug --no-bundle
```

产物：`src-tauri/target/debug/yanwenzi.exe`。

构建 release 可执行文件：

```powershell
npm run tauri build -- --no-bundle
```

产物：`src-tauri/target/release/yanwenzi.exe`，实际路径以构建输出为准。正式发布与便携版验收在后续阶段完成。

当前开发版可将 release 可执行文件压缩为测试包（不代表完整产品便携版）：

```powershell
New-Item -ItemType Directory -Force -Path dist | Out-Null
Compress-Archive -Path "src-tauri/target/release/yanwenzi.exe" -DestinationPath "dist/颜喵 YanMew-stage1-test.zip"
```

完整产品的便携版还必须包含本地 Embedding 模型、随包石头剪刀布插件及其清单、所需运行资源与许可证文件，并保留程序预期的相对目录结构；不能只压缩 exe。发布打包流程在对应功能实现后完善，并在干净目录中验证离线首次启动。发布包不包含开发者的数据库、密钥、聊天和个人存档。
