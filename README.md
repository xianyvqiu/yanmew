# 颜喵 YanMew

**住在桌面上的 AI 小伙伴，记得聊天，也拥有自己的日常。**

从一只颜文字小猫开始，陪它聊天、旅行、收集小礼物，或换成你喜欢的透明图片形象。

Windows 桌宠 · 多人设 · 长期记忆 · 图片创作 · 小游戏 · 现实记账

[下载颜喵](https://github.com/xianyvqiu/yanmew/releases) · [开始使用](#开始使用) · [功能一览](#功能一览) · [更新与备份](#更新与备份) · [问题反馈](https://github.com/xianyvqiu/yanmew/issues)

---

颜喵是一款 Windows 桌面陪伴应用。你可以在透明宠窗直接聊天，也可以打开聊天详情，管理会话、查看记忆，让不同人设拥有各自的形象和经历。

**模型服务由你选择，数据保存在本机。** 应用不附带聊天 API Key；聊天、识图、生图等能力使用你配置的服务。本地自带的 Embedding 模型用于检索记忆，不是离线聊天模型。

支持 **Windows 10/11 x64**，需要 WebView2 Runtime。当前处于早期版本阶段，下载和更新请以 [Releases](https://github.com/xianyvqiu/yanmew/releases) 中实际提供的附件及说明为准。

## 功能一览

### 🐾 桌面上的伙伴

- **颜文字与图片形象**：使用默认电子小猫、四位预置图片人设，或上传自己的透明 PNG/WebP。图片表情可逐项上传，也可通过生图服务生成，预览满意后再接受。
- **日常互动**：点击、摸摸、喂食、拎起和抛接，伴随饥饿、待机、无聊、睡眠与出行状态。生活节奏可在“时间与桌宠”中调整。
- **游走与停靠**：在宠窗“…”菜单开启全屏游走；拖到屏幕侧边可探头，拖到底边可坐下或趴下。游走时有概率追逐鼠标，追到后会等待摸摸。
- **食物与饰品**：投喂免费 Token 小点心或用喵币购买食物，为伙伴制作和佩戴多件饰品，调整位置、大小和前后层级。拿着食物时，右键或 Esc 可取消。

默认“电子小猫”之外，还内置四位可编辑、可删除的图片人设，每位带有初始图及三十张互动与情绪图：

### 💬 聊天与个性化

- 宠窗快捷聊天与聊天详情共用会话，支持流式回复、Markdown、上传图片、中断、重说和继续生成。
- 每个人设可拥有多个会话；会话支持重命名、置顶和绑定用户设定。
- 按人设保存聊天背景、气泡样式和双方文字颜色。同一人设的会话共用外观，背景图片支持裁剪、透明度和模糊度调整。
- 配置相应服务后，可以请 AI 画图、按需搜索和读取公开网页。图片模式下，AI 可按语境切换已启用的桌宠表情，也可从绑定的聊天表情包库发送图片。
- 普通聊天中，可明确要求 AI 切换亮暗主题、把本轮上传的图片设为背景、调整聊天外观，或查询及领取当天签到奖励；每天只能领取一次。

### 📖 记住共同经历

- 对话结束后生成短期记忆，再整合为可查看、编辑并追溯来源的长期记忆。聊天时结合全文与向量检索查找相关往事。
- 聊天、记忆与记事本按会话保存；上下文不足时减少本次请求携带的较旧内容，不因此删除历史记录。
- **Skill 仓库**保存提示词资料，可绑定到多个人设；支持上传 UTF-8 Markdown 文件，也可请 AI 新增和修改。Skill 用于提供资料，不执行脚本。
- **聊天表情包库**支持批量导入 PNG/JPEG/WebP/GIF，填写介绍与标签，再绑定给人设使用。已发送的图片不随收藏删除而消失。
- 开启人设自调后，AI 可依据明确的长期反馈小幅调整当前设定；可查看初始设定、当前设定及差异。

### ✉️ 旅行与日常

- **出行与来信**：伙伴会外出旅行，途中寄信，返回后带来伴手礼与游记。邮箱、游记和伴手礼支持搜索及按出行筛选；邮件和伴手礼可点击卡片右侧星星收藏，并使用“只看收藏”筛选。
- **伴手礼图片**：开启并配置生图服务后，可为新伴手礼生成图片；关闭或生成失败时保留文字内容。
- **提醒与邮件**：设置一次性或循环提醒，到点显示桌宠通知；配置 SMTP 并验证收信邮箱后，可同时发送邮件提醒。关闭应用期间无法实时发信。
- **天气与日历**：查看实况、小时和多日预报、天气预警、台风关注信息及穿衣参考；日历支持公历、农历、节日和自定义日期。
- **喵币与签到**：每日签到领取喵币，节日有特别祝福和奖励。食物、饰品与小游戏共用钱包，可查看收支账单和统计。

### 💰 独立的现实账本

在“设置 → 现实记账”记录人民币收支，与喵币钱包分开保存。支持分类、资产、预算、周期账单、日历及统计，也可以明确告诉 AI：“帮我记一笔现实支出，午餐 25 元。”

账本不连接银行，也不实际转账或扣款。现实财务资料只进入**全量备份**，不随人设、会话或小游戏资料包分享。

### 🎮 小游戏与社区插件

内置 **剪刀石头布、掷骰子比大小、接星星、我的家、扫雷、2048**，在“设置 → 小游戏插件”中打开和管理。扫雷和 2048 支持免费游玩与喵币奖励局，奖励局各自每天最多 5 局；未结束的棋盘重新打开后可继续。

在小游戏插件页点击“社区小游戏”，可以浏览作品卡片、查看 README 和下载游戏。下载的 `.yanmew-game` 包需返回颜喵，从本地安装入口安装；安装完成后可删除下载的包。已安装的第三方游戏可停用或卸载，自带游戏不可卸载。

插件需要使用喵币或联网时，会先申请权限，由你确认。插件的设置和存档独立保存；“清除数据并重载”会清空该游戏的存档、设置与授权，保留钱包余额及已发生的账单。

想制作自己的小游戏？查看[完整开发与发布教程](plugins/sdk/README.md)，或访问[社区小游戏仓库](https://github.com/xianyvqiu/yanmew-community-games)。

## 开始使用

### 1. 下载与运行

前往 [GitHub Releases](https://github.com/xianyvqiu/yanmew/releases)，下载 `YanMew-版本号-windows-x64.zip`，完整解压到可写目录，双击 `yanwenzi.exe`。

不要直接在压缩包中运行，也不要只复制 EXE；旁边的 DLL 和 `resources/` 都需要保留。GitHub 自动提供的 `Source code` 归档是源码，不能直接作为程序运行。若发布页提供安装器，也可按安装向导安装。

普通使用无需安装 Node.js、Rust 或 Python。便携版需要系统已安装 WebView2 Runtime。

### 2. 配置聊天

1. 点击宠窗 **`…` → 设置 → 提供商**，添加连接名称、Base URL 和自己的 API Key。
2. 在聊天用途配置中选择连接、填写模型名并保存，再测试连接。
3. 点击宠窗底部聊天图标输入，或通过 **`…` → 聊天详情** 打开完整聊天界面。

通用连接可供聊天、记忆、识图、生图复用，各用途单独选择模型。记忆和识图可以跟随聊天；单独配置识图时，先由识图模型理解图片，再交给聊天模型回答。所选服务与模型仍需支持对应能力。

### 3. 按需启用可选能力

- **记忆检索**：完整便携包自带本地 `BAAI/bge-small-zh-v1.5`，也可配置联网 Embedding 服务；本地模型不可用时退回全文检索，不自动上传记忆。
- **联网搜索**：默认关闭，支持 Tavily、博查及自定义 Tavily 兼容接口，填写自己的 Key 后开启。
- **生图与图片创作**：配置并开启生图用途。根据初始形象生成表情时，推荐选择支持参考图输入的模型；结果先预览，接受后才正式使用。手动上传图片不需要生图服务。
- **邮件提醒**：在通用设置中填写发信邮箱、收信邮箱和 SMTP 配置，完成验证码验证。

联网模型、生图、搜索及邮件等服务的额度与费用由对应服务商计算，与游戏中的喵币无关。

## 更新与备份

### 程序更新

在“设置 → 关于颜喵”查看版本、构建编号、资料目录和仓库链接。每次启动会自动检查一次正式版本，也可点击“检查更新”；只有点击更新才会下载。

发现新版后，页面会显示发布说明、下载链接和“更新并重新启动”按钮。更新会备份并保留资料，完成后重新启动。请先保存正在编辑的内容。

没有应用内更新入口的旧版本，可下载发布页的 `YanMew-Update.exe`，选择旧版 `yanwenzi.exe` 所在文件夹，按提示正常退出旧版后更新，无需手动复制 `data/`。更新依赖发布页提供可公开访问的完整更新附件。

### 资料与隐私

- **便携版数据**保存在 EXE 同目录的 `data/`，数据库为 `data/yanwenzi.db`。移动程序时需保留完整 `data/`。
- **安装版数据**保存在 `%LOCALAPPDATA%\YanMew\data`，与便携版独立，不自动合并。
- **API Key 与 SMTP 授权码**通过 Windows DPAPI 加密保存，不随备份导出；换电脑后需重新配置。
- **备份导出**支持全量、人设、会话、用户设定及小游戏使用数据等范围，可在通用设置中操作。

**本地保存不等于所有功能离线。** 聊天、记忆生成和识图会将所需内容发送给你选择的模型服务；生图、搜索、天气和邮件按各自配置联网。本地 Embedding 在本机处理检索。

全量恢复会替换全局设置、喵币钱包、账单及现实账本等数据，确认前请阅读导入预览并备份现有内容。主动卸载会删除对应版本的个人资料，需要保留的内容请先导出。

## 常见问题

<details>
<summary><strong>关闭聊天窗口后，为什么宠物还在？怎么完全退出？</strong></summary>

关闭聊天详情、设置窗口或隐藏宠窗不等于退出。请在系统托盘图标右键选择“退出”，或在“关于颜喵”中点击“退出应用”。

</details>

<details>
<summary><strong>能完全离线聊天吗？</strong></summary>

应用不附带本地聊天模型。内置 Embedding 只用于记忆检索；聊天需要配置可访问的模型服务。提醒、资料管理和小游戏等功能不需要每次调用聊天模型。

</details>

<details>
<summary><strong>有预置图片人设，为什么还不能生成新表情？</strong></summary>

预置形象可以直接使用；生成新表情还需要开启生图用途，选择支持参考图输入与图片输出的模型。也可以手动上传透明图片。

</details>

<details>
<summary><strong>为什么检查更新时没有显示新版？</strong></summary>

更新只检查主仓库的 Latest 正式版，不包含草稿或预发布版。当前程序与发布版本相同或更新时，不会显示更新按钮；没有公开正式版本、附件不完整或网络失败时，页面会说明具体状态。

</details>
