# 现实记账系统

> 当前实现基线（2026-11-08）：源码及备份v26，最新正式包20261108-163147为v26。本文中的阶段版本仅说明引入历史；实际交付范围与默认值见[当前实现与版本范围](当前实现与版本范围.md)。


日期：2026-10-20。独立全局模块，人民币CNY，精度为分；与喵币账单及用户银行实际扣款无关。

## 产品与交互

设置新增现实记账入口，原账单入口命名为喵币账单。现实记账首页显示本月收支、总资产摘要、日月年预算卡、今日收支和近期账单；预算卡点击编辑，不另设预算页。总览、账单、统计、资产、周期、分类和日历共用常驻底部导航，点击直接切换；各页不重复展开其他模块表单。沿用颜喵亮暗主题、暖灰/炭黑表面与樱粉点缀，响应式排列、卡片搜索/排序/分页、详情和短动效，不照搬手机参考图。

账单字段为标题、收入/支出、分类、所用资产、简介、人民币金额、发生本地日期时间、记账者和来源。手动、AI及周期生成明确区分；AI记账者使用当前人设名称快照，删除人设或会话不删除账单。手动录入允许填写记账者。金额按十进制文本精确转换为整数分，禁止二进制浮点记账。

分类预置食物、宠物、交通、购物、社交、学习、娱乐、日常水电网费、房租、生活费、医药、订阅会员服务、旅游、工资、奖金、保险、外快、投资、其他。支持新增、修改、查询和删除。引用过的分类归档保留历史，仍被活动周期使用时先处理周期，不静默改掉分类。

资产为独立资金池，初始默认资产、储蓄资产、旅游资产均为0。总资产等于全部资金池余额之和，不再额外叠加一个总额。修改总资产时在默认资产记录差额校准；修改单个资产余额同样记录校准。校准不计收入、支出或预算。余额允许负数，避免没有录入期初余额时无法记账。默认资产角色可切换，不能删除当前默认资产；有余额或未结束周期的资产需要先处理后删除。删除采用归档，历史账单仍可查。

预算按日/月/年分别选填，空值为未设置，0表示零支出目标；三个周期独立，不自动互相覆盖。按自然日/月/年计算已支出、剩余或超支。日均消费=本周期支出/已过天数（含今天）；剩余每日可花=非负剩余预算/剩余天数（含今天）。收入不抵消预算支出，校准不参与预算。没有预算时只显示实际支出和日均消费，不伪造额度。

统计沿用收支上下柱、独立分类占比圆环、分类汇总和资产收支排行，支持昨日、最近7天/1个月/6个月/1年及自定义日期。预算按自然周期，不能把图表任意时间筛选当成预算周期。日历继续显示农历、今天和节日，按需叠加实际收支及未来预计周期；预计与待确认项目不进入实际收支。

## AI工具

只开放普通聊天，主动消息、记忆、旅行生成、继续生成不调用现实记账写工具；重说不重复执行写入。AI必须区分现实金额与喵币：用户明确说现实钱、人民币等可直接记；含糊时必须先问，未明确前不调用写账单工具。仅提到价格、假设举例或咨询不能自动入账。

工具可查询必要资产、分类及账单，管理分类、创建一次性账单或周期计划。缺少金额、资产、分类或日期含义不明时询问，不捏造消费。已存在默认资产可在用户未指定时使用，但需在结果说明。分类不合适时先查询，按用户意图新增。金额用元的十进制字符串。只按需求读取相关账单，不把全量财务数据自动塞进每轮提示词。

写入使用稳定操作编号；同一操作重试只返回原结果，不重复记账。修改分类等带revision，旧版本失败后重新查询。事务成功才向用户说已经记好。

## 周期与漏期确认

周期为每N天/周/月/年，锚定首次日期时间；每月31日遇短月取月末，每年2月29日遇平年取2月28日，随后仍按原始锚点计算，不能逐月漂移。任务可暂停、编辑未来期次或结束。

运行期间正常到期自动记录。启动时已错过的期次及恢复导入的过期期次列为待确认，不自动补记；宠窗仅提示待确认数量，设置页展示原日期、金额、分类及资产，用户可逐项选择、全部补记或跳过。取消弹窗保留勾选；全部操作仅处理页面已知throughId及之前的项目，不把之后发现的漏期混入确认。分批发现漏期不截断任何期次。补记用原计划日期，创建时间使用实际处理时间。唯一(schedule_id,generation,sequence)防止重复；修改周期锚点或规则递增generation，只重新安排未来期次。删除已生成账单不会让调度器再生同一期。

每个待确认期次保存当时模板快照；修改计划不改旧账单或已发现的漏期金额。结束计划停止新增期次，已发现的待确认项仍由用户处理。暂停期间不生成新账单，恢复后过去到期项目先询问。未来计划不提前记入消费。

## 数据与升级

正式v18升级新增real_assets、real_categories、real_schedules、real_entries、real_occurrences、real_budgets、real_operations七张独立表及必要索引；不修改既有喵币表。金额字段是整数分，合计使用i128，IPC金额以十进制字符串返回。

资产余额由实际账单和校准记录计算，不另存一份可失去同步的余额。实际发生时间保存用户认定的本地记账时间，切换电脑时区不把旧账单挪到另一天；自动周期按电脑当前本地日历触发。每天/月/年统计按此本地记账日期归属。

现实记账只进入全量备份，不随人设、会话、用户设定或小游戏包导出。全量恢复保留现实记账内部ID关系和周期唯一键，不重放历史收支；过期期次恢复后仍需确认。旧v6–17备份恢复为默认空现实账本。已有数据升级前沿用项目的数据库备份与事务迁移。

## 实现职责与接口

`src-tauri/src/real_money.rs`负责精确金额、事务写入、余额校准、版本冲突与操作回执；子模块records负责查询与预算统计，cycles负责周期日期及漏期快照，tools负责普通聊天Function Calling，commands负责窗口权限与后台线程调度。jobs沿用现有循环，每15秒检查到期项目，一次最多处理每计划128项，后续扫描继续发现剩余项目；不截断历史。

Tauri接口：get_real_money_overview、query_real_money、mutate_real_money、list_real_money_tasks、get_real_money_calendar、get_real_money_operation仅设置窗可用；get_real_money_pending仅返回数量及最大期次编号，允许主宠窗提示。修改后发送real-money-changed，调度失败发送real-money-error。

模型工具为list_real_money_assets、list_real_money_categories、save_real_money_category、delete_real_money_category、record_real_money、query_real_money_entries。写入复核活动请求、当前会话及上下文，记录可信人设名称。record_real_money要求confirmedRealMoney=true；含糊时先问的语义判断由提示词指导，不能将模型传入的布尔值宣传为程序已经独立理解用户原话。用户决定漏期补记的操作不向模型开放。

前端realMoneyApi传递金额文本；RealMoneyPanel与表单、资产、预算、任务、日历子组件复用现有设置外壳和滚动弹窗。图形只复用LedgerCharts的绘制能力，通过格式上下文显示人民币，喵币仍使用原格式与独立查询。写入结果未知时保留原操作编号，先查询回执并允许同一请求重试；不因连接中断生成新编号。

## 分层入口与翻月交互（增量S）

预算卡在首页展示并点击编辑；周期任务入口显示运行数及漏期待确认数量，完整漏期处理仍在周期模块。账单明细只显示分页记录和详情入口，统计摘要及图形只在数据面板展示；两者默认收起筛选工具，展开后可查日期、分类、资产等，已应用条件和页码不因切换而清空。主页保留今日收支与三种预算卡，不堆放各模块的筛选和管理表单。

普通节日日历与记账日历共用CalendarView翻月交互：新月份就绪前保留旧网格、暂停旧日期选择，成功后下一月从右向左滑入、上一月从左向右滑入。直接选月及回到今天按实际月份方向切换；同月刷新不重播。动画240ms，只改变transform/opacity，系统减少动态效果时直接切换。网格保留六行，月份行数不同也不突然收缩。失败保留旧网格并提示重试，过期请求不能覆盖最后选择。

增量S只改前端展示与交互，没有数据库、金额、预算、周期、AI工具或备份规则调整。本增量已包含在20261020-173045便携包中，本机v19资料已完整接续并核对；完整原生WebView2交互仍待实机验收。
