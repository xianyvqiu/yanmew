# 追逐鼠标互动设计

> 当前实现基线（2026-11-09）：源码及备份v26，最新正式包20261109-143800为v26。本文中的阶段版本仅说明引入历史；实际交付范围与默认值见[当前实现与版本范围](当前实现与版本范围.md)。


## 触发

用户开启全屏游走、未停靠，且活动允许游走时，在每个超过原8逻辑像素到达容差的移动计划中抽取一次5%概率。待机、睡觉、出行、报错、拖动、抛接、隐藏、聊天或其他既有暂停条件下不启动；不逐帧抽取，不为无效微移制造表情切换。

## 过程与反馈

追逐与普通移动使用同一个Desktop取消令牌及原生窗口通道。约每30ms更新当前位置，按实际经过时间以180逻辑像素/秒向最新鼠标位置移动；首次确实接触可见立绘后停止，切到`wait_pet`并在立绘旁显示“等摸摸”，从到达时开始等待5秒。透明留白不算接触，不再使用额外10像素接近范围。

等待期间左键单击结束追逐，通过既有互动结算显示当前人设点击开心反馈3秒，不再随机惊讶或害羞。按下鼠标到松开的短暂过程不自行取消等待；超过普通拖动阈值则取消追逐，改用已有拎起逻辑。若等待超时，复用已启用的“难过”或“伤心”聊天图片，持续3秒后结束；无匹配图片或颜文字模式用本地失落颜文字。失落不调用模型、不重新回答或写聊天记录。

## 取消与界面

状态/人设/会话变化、暂停、停靠、隐藏、聊天、拖动、抛接、尺寸/DPI或工作区改变时结束本次追逐，旧线程不能恢复已取消动作。鼠标离开当前工作区则结束，不跨着屏幕边界追逐。位置受当前工作区约束，鼠标停在不可达到的角落时不会误报追到。等待和失落反馈期间不再发起新的追逐。结束后继续既有低频游走节奏。

追赶复用当前方向的行走图片，等待/失落使用本地表情和既有图片缓存切换。侧边文字不拦截点击，使用主题配色；动效仅transform/opacity，支持减少动态效果。

## 资料与资源

v23正式增加`wait_pet`图片类别，沿用上传、生成、预览接受、启停、手动颜文字编辑及备份恢复。专属互动的已启用正式图片也开放给聊天表情工具，选择图片不启动真实互动。四位内置角色各增加一张参考默认立绘的独立等摸摸PNG，已有角色仅按初始设定与默认图核验后一次性补缺，用户编辑和已删角色不覆盖。上抛/下落各四张同步更换为正立竖直运动构图，保留原落地资源。新图精确提示保存在资源目录清单。

源码实现和编译测试不代表旧EXE已更新；Windows原生追逐手感需新构建后实机验收。

## 2026-10-22 接触与冷却修正

每次合格移动的5%概率不变，按用户确认不设置追逐时长上限；一次追逐结束或被点击、拖动、打开聊天、切换上下文等打断后，按全局设置冷却，默认10分钟，普通游走不受冷却影响。追到判定去除额外10像素范围：图片使用当前实际contain尺寸及32×32透明度命中图，透明留白不算接触；目标点选择不透明区域，避免中心恰好透明时追到目标仍无法接触。图片未就绪时不提前宣告接触，颜文字使用正文范围。

等摸摸提示是宠窗根部独立元素，纳入原生可见区域与布局测量；优先放左右，空间不足时放下方或上方空白，并避让已有按钮，不挤在立绘内部。出行时仍不可用。

## 等待时长

等待摸摸改为5秒，5秒内点击使用开心互动并退出；到时未点击才显示3秒失落反馈。等待阶段的可点击判定与状态切换共用同一个5秒常量。冷却为结束或中断后默认10分钟，可在全局设置→基础服务→时间与桌宠调整，追逐本身不设时长上限。

配置键为`pet_chase_cooldown_minutes`，正整数分钟，默认10；无需数据库结构迁移，沿用设置备份恢复。运行中调整会按最近一次追逐结束时间重新判断间隔，普通游走不受影响。冷却状态沿用当前进程生命周期，重启后不保留倒计时。
