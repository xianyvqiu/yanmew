# 颜喵 YanMew 前端设计文档

- 日期：2026-09-08
- 类型：前端界面与交互设计
- 状态：已确认
- 说明：本文只描述界面结构、视觉层次和交互，不包含实现代码。

## 1. 设计目标与原则

- 仅面向 Windows，视觉上像桌面小宠物，不做传统后台管理系统。
- 主宠窗保持小、透明、无边框、置顶；聊天窗轻气泡风；设置窗使用圆角卡片，但整体仍要轻。
- 颜文字是核心视觉元素，字体要大、清晰；状态优先用颜文字和短气泡表达。
- 桌宠本体颜色按人设绑定，只影响基础颜文字；饰品层、气泡、窗口背景不跟随该颜色。
- 所有错误统一为红色感叹号，点击后显示中文错误气泡，不弹系统风格报错页。
- v1 不引入图片素材型饰品、旅行礼物或宠物形象；饰品和礼物全部用文字、颜文字或 emoji 表达。
- 文案使用简体中文；代码、路径、配置键保持原文。

## 3. 主宠窗

### 3.1 画布

- 默认大小：`320×240`。
- 默认位置：屏幕右下角；用户拖动后记住位置，下次启动恢复。
- 窗口透明、无边框、置顶。
- 透明空白区域鼠标点击穿透，只让颜文字本体和可交互控件接收鼠标事件。

### 3.2 主宠窗布局

```text
┌────────────────────────────────┐
│           [饰品层]              │
│         ฅ^・ﻌ・^ฅ               │
│                                 │
│   ┌─────────────────────┐       │
│   │ 气泡：饿/无聊/说话…  │       │
│   └─────────────────────┘       │
│                                 │
│        [聊天 / 写信]             │
│              [!]                │
└────────────────────────────────┘
```

- 基础颜文字：使用当前会话所属人设的 `color` 渲染。
- 饰品层：佩戴饰品时显示在头顶；未佩戴则隐藏。
- 聊天按钮：
  - 正常状态显示“聊天”。
  - 当前会话 AI 出门中时显示“写信”。
- 红色感叹号：出错或休眠时显示，点击后弹出中文错误气泡。
- 气泡：临时显示 AI 说话、活动提示、错误信息，自动消失。

### 3.3 主宠窗状态

- 正常：基础颜文字 + 当前人设颜色。
- 饿：显示对应表情或气泡，例如“好饿…”；颜色仍使用人设颜色。
- 无聊：显示无聊表情或气泡。
- 睡觉：显示睡觉表情，交互会减少睡眠计时或唤醒。
- 吃东西：喂食后短暂显示吃东西表情。
- 说话：AI 开始回复前先切换说话表情，再显示流式气泡。
- 思考中：生成表情、记忆整合或工具调用时显示思考表情。
- 出门中：显示出门中表情；聊天按钮变为“写信”。
- 休眠：显示红色感叹号，不主动说话。

### 3.4 左键与右键

- 左键单击：随机点击互动，触发点击类表情，并给当前会话亲密度 +1。
- 右键菜单：

```text
┌────────────┐
│ 聊天        │
│ 喂食        │
│ 摸摸        │
│ 饰品        │
│ 设置        │
│ 退出        │
└────────────┘
```

- 出门中时，“喂食”“摸摸”置灰，点击后只弹“它出门啦”。
- 喂食、摸摸成功时更新亲密度和宠物状态。
- 退出关闭整个应用，包括所有窗口、托盘和后台任务。

## 4. 系统托盘

- 托盘图标使用应用图标。
- 左键单击托盘图标：显示或聚焦主宠窗。
- 右键菜单：

```text
┌────────────┐
│ 显示宠窗    │
│ 设置        │
│ 退出        │
└────────────┘
```

- “退出”与主宠窗右键退出行为一致，关闭整个应用。

## 5. 聊天窗

### 5.1 聊天窗布局

```text
┌──────────────────────────────────┐
│ 颜喵 YanMew    [新建] [记忆]      │
│ ┌──────────────────────────────┐ │
│ │ 会话列表                      │ │
│ │ ○ 会话A  ⋯ [重命名] [删除]   │ │
│ │ ○ 会话B  ⋯ [重命名] [删除]   │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 消息气泡区                    │ │
│ │ 用户消息靠右                  │ │
│ │ AI 消息靠左                   │ │
│ │ [删除] [编辑] [重说]          │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 输入框               [发送]   │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

### 5.2 顶部与会话列表

- 标题：`颜喵 YanMew`。
- 新建会话按钮：创建当前人设下的新会话。
- 记忆按钮：打开当前会话的记忆小窗。
- 会话列表按人设隔离；切换当前人设后，历史会话列表同步切换。
- 会话标题由 AI 自动生成，用户可重命名。
- 会话可切换、继续、删除。

### 5.3 消息区

- 用户消息靠右，AI 消息靠左。
- AI 回复为流式输出；AI 说话前先切换桌宠表情。
- 每条消息下方提供：
  - `删除`：只删除该条消息，后续消息保留。
  - `编辑`：只修改文本，不触发重新生成；用户消息和 AI 消息都可编辑。
  - `重说`：仅当最后一条是 AI 回复时显示；重新生成对最后一条用户消息的回复，并覆盖原 AI 回复。
- 删除最后一条后，若新的最后一条是 AI 回复，则它可重说。

### 5.4 输入区

- 支持多行文本输入。
- 发送后输入框清空。
- 流式回复期间发送按钮置灰，避免重复发送。

### 5.5 出门中状态

- 当前会话 AI 出门中时，聊天输入区置灰。
- 顶部提示：`它出门啦，先写信吧`。
- 主宠窗聊天按钮变为“写信”。
- 用户只能写信，不能进行正常聊天。

### 5.6 聊天窗背景

- 聊天窗背景按人设隔离，切换人设后跟随切换。
- 背景层位于消息气泡、会话列表和输入框下方。
- 背景效果由三部分组成：
  - 背景图片：`jpg / png / webp`，单张最大 `10MB`。
  - 透明度：`0–100%`。
  - 模糊度：`0–40px`。
- 未设置背景图时使用默认纯色背景。
- 设置入口：设置 > 人设 > 对应人设卡片 > 聊天窗背景。

## 6. 写信界面

### 6.1 打开方式

- 主宠窗出门中时点击“写信”。
- 设置 > 出行 > 邮箱中点击“写信”。
- 回复某封 AI 来信时，复用写信界面并带上回复目标。

### 6.2 写信界面布局

```text
┌──────────────────────────────────┐
│ 写信给：当前会话 AI              │
│ 当前会话：会话A                  │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ 写信正文                     │ │
│ │                              │ │
│ │                              │ │
│ └──────────────────────────────┘ │
│                                  │
│ [取消]                  [发送]   │
└──────────────────────────────────┘
```

### 6.3 写信规则

- 出门中时可连续写多封。
- 每封用户来信都会得到 AI 回信。
- 回信延迟默认 `10–30` 分钟随机。
- 已回复的信不能再回，邮箱中回信按钮置灰。
- 写信和回信使用当前会话人设、记忆和记事本。

## 7. 设置窗

### 7.1 设置导航

```text
┌──────────────┬──────────────────────────┐
│ 提供商        │                          │
│ 人设          │                          │
│ 会话与聊天记录│        内容区             │
│ 宠物状态      │                          │
│ 时间与宠物    │                          │
│ 空闲气泡      │                          │
│ 提醒          │                          │
│ 记忆          │                          │
│ 天气          │                          │
│ 出行          │                          │
│ 饰品          │                          │
│ 通用          │                          │
└──────────────┴──────────────────────────┘
```

### 7.2 提供商

- 列表展示：名称、模型、聊天当前项、记忆专用项。
- 新增/编辑字段：
  - 名称
  - base URL
  - API Key
  - 模型名
- 每个提供商有“测试连接”按钮。
- 聊天当前提供商只能启用一个。
- 记忆提供商可单独指定；未指定时默认跟随聊天提供商。

### 7.3 人设

- 人设列表显示：
  - 人设名称
  - 是否当前使用
  - 当前人设文本
  - 初始设定文本
  - 本体颜色色块
  - 自调开关
  - 最近 AI 调整时间
- 操作：
  - 切换为当前人设
  - 编辑当前人设
  - 保存为初始设定
  - 从初始设定恢复
  - 选择桌宠本体颜色
  - 设置聊天窗背景
  - 重新生成表情库
- 自调开关默认开启，按钮要明显。
- 颜色选择器：预设色板 + 自定义颜色，存储为十六进制颜色。
- 聊天窗背景：上传图片、预览、透明度滑块、模糊度滑块、恢复默认。
- 创建新人设后自动生成表情库；无可用 provider 时提示稍后手动生成。

### 7.4 会话与聊天记录

- 展示当前人设下的所有会话。
- 每个会话可：
  - 查看历史消息
  - 切换为当前会话
  - 重命名
  - 删除
- 历史消息查看只读；编辑、删除、重说仍在聊天窗完成。

### 7.5 宠物状态

```text
┌────────────────────────────────┐
│ 当前会话：会话A                │
│ 亲密度：42 / 50                │
│ 喵币余额：30                   │
│                                │
│ [每日签到]                     │
│ ┌────────────────────────────┐ │
│ │ 石头剪刀布                  │ │
│ │ [剪刀] [石头] [布]          │ │
│ │ 今日剩余：18 次             │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- 亲密度按会话显示；聊天轮数、点击、摸摸、喂食增加亲密度。
- 喵币为全局用户级余额，删除会话不影响。
- 每日签到：本地时间每天 0 点刷新，每次随机获得 `1–10` 喵币。
- 石头剪刀布：
  - 用户选择剪刀/石头/布。
  - 系统随机出拳。
  - 赢 `+5`、输 `-4`、平局 `0`。
  - 开始前余额必须 `≥ 4`。
  - 每天最多 `20` 次。

### 7.6 时间与宠物

- 饥饿触发时长。
- 无聊触发时长。
- 多久没互动进入睡觉。
- 全部数值可编辑并保存。

### 7.7 空闲气泡

- 空闲气泡触发时长。
- 上下文选择：
  - 当前会话
  - 该人设最近会话
  - 人设 + 环境
- 默认值：优先当前会话；无当前会话时回退到该人设最近会话；仍无则使用人设 + 环境。

### 7.8 提醒

- 提醒列表显示：内容、类型、状态、触发时间、来源。
- 支持新增、编辑、删除。
- 类型：
  - 一次性
  - 每天
  - 每周
  - 每月
- 状态：
  - 未完成
  - 完成
  - 已过期
- 编辑项：时间、详情、状态、循环规则。
- 到点仅提醒一次；应用关闭期间的一次性提醒，下次启动询问补提醒或标过期。

### 7.9 记忆

- 短期记忆字数范围。
- 长期记忆字数范围。
- 手动合并字数范围。
- 工具调用轮数，默认 `3`。
- 记事本长度上限，默认 `4000` 字。
- 所有字数单位为中文汉字个数。

### 7.10 天气

- 和风天气 API Key 输入框，可选。
- 显示定位状态：已定位 / 无权限 / 定位失败。
- 显示天气来源：Open-Meteo / 和风天气 / 不可用。
- 保存后不展示已保存的明文 Key。

### 7.11 出行

- 默认展示当前会话，页内可切换会话。
- 显示当前出行状态：在家 / 出门中 / 已回来。
- 显示最近旅行历史。
- 两个标签页：邮箱、伴手礼。

### 7.12 饰品

- 当前会话饰品列表。
- 每项显示：
  - 饰品名称
  - 头顶显示文字/emoji/颜文字
  - AI 按人设口吻写的简介
  - 来源：制作 / 旅行带回
  - 是否佩戴
- 操作：
  - 佩戴
  - 卸载
  - 删除未佩戴饰品
- 删除后不可恢复。
- AI 发起制作请求时，在主宠窗弹出确认气泡/卡片：
  - `给你买`
  - `没有钱了`
- 余额足够才可完成制作。

### 7.13 通用

- 开机自启开关，默认关闭。
- 应用版本信息。
- 退出应用。

- 可查看出发时间、计划返回时间、实际返回时间和带回结果。

## 10. 错误、空态与加载

### 10.1 错误

- 主宠窗显示红色 `!` 感叹号。
- 点击感叹号弹出中文错误气泡。
- 错误类型包括：无 Token、连接失败、限流、后台记忆整合失败等。
- 休眠状态下 AI 不主动说话。

### 10.2 空态

- 未配置提供商：聊天窗提示“请先在设置中添加 API 提供商”。
- 未配置人设：使用默认“喵喵桌宠”，设置页提示用户配置。
- 无会话：聊天窗显示“新建一个会话开始聊天”。
- 无信件：邮箱显示“还没有信件”。
- 无伴手礼：伴手礼显示“还没有收到伴手礼”。
- 无饰品：饰品管理显示“还没有饰品”。

### 10.3 加载

- 流式回复：AI 气泡持续追加文字，不显示全局 loading。
- 生成表情库：按钮显示“生成中…”。

## 12. 关键交互流程

### 12.1 正常聊天

1. 用户点击主宠窗“聊天”。
2. 打开聊天窗，选择或新建会话。
3. 用户输入并发送。
4. AI 先切换表情，再流式输出回复。
5. 回复完成后后台检查记忆整合、记事本工具和人设自调。

### 12.2 AI 出门

1. 满足在线时间和空闲条件后，主宠窗弹出“我出去玩啦”。
2. 桌宠切换为出门中状态。
3. 聊天按钮变成“写信”。
4. 用户写信后等待 `10–30` 分钟随机回信。
5. AI 回来时带回伴手礼，并生成旅行总结短期记忆。

### 12.3 制作饰品

1. AI 达到亲密度档位并发起制作请求。
2. 主宠窗弹出确认：`给你买` / `没有钱了`。
3. 用户确认且余额足够，扣喵币并生成饰品。
4. 饰品进入饰品管理，用户可佩戴或卸载。

### 12.4 从聊天创建提醒

1. 用户在聊天中要求提醒。
2. AI 通过 function calling 创建结构化提醒。
3. 设置 > 提醒中出现该提醒，可手动编辑时间、详情、状态。

## 13. 前端与 Rust 接口约定

- 所有数据通过 Tauri command 获取或提交。
- AI 流式输出通过 Tauri event 推送到前端。
- 前端不直接读写 SQLite，不直接调用 AI 提供商。
- API Key 只在设置表单输入，前端不展示已保存的明文 Key。
- 前端统一处理错误事件，映射为红色感叹号和中文错误气泡。
- 前端只展示当前会话的出行、信件、伴手礼、饰品和记忆数据。
- 所有删除操作使用确认弹窗；删除会话、人设、饰品等不可恢复操作需要二次确认。
