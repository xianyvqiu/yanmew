# 颜喵 YanMew 前端设计文档

- 日期：2026-09-08
- 类型：前端界面与交互设计
- 状态：已确认
- 说明：本文只描述界面结构、视觉层次和交互，不包含实现代码。

## 1. 设计目标与原则

- 仅面向 Windows，视觉上像桌面小宠物，不做传统后台管理系统。
- 主宠窗保持小、透明、无边框、置顶；聊天窗轻气泡风；设置窗使用圆角卡片，但整体仍要轻。
- 颜文字是核心视觉元素，字体要大、清晰；状态优先用颜文字和短气泡表达。
- 桌宠本体颜色按人设绑定，只影响基础颜文字；饰品层、气泡、窗口背景不跟随该颜色。
- 所有错误统一为红色感叹号，点击后显示中文错误气泡，不弹系统风格报错页。
- v1 不引入图片素材型饰品、旅行礼物或桌宠形象；饰品和礼物全部用文字、颜文字或 emoji 表达。
- 文案使用简体中文；代码、路径、配置键保持原文。

## 3. 主宠窗

### 3.1 画布

- 默认大小：`320×240`。
- 默认位置：屏幕右下角；用户拖动后记住位置，下次启动恢复。
- 窗口透明、无边框、置顶。
- 透明空白区域鼠标点击穿透，只让颜文字本体和可交互控件接收鼠标事件。
- 隐藏宠窗后，窗口缩小为只保留“显示宠窗”按钮；点击该按钮恢复完整宠窗。

### 3.2 主宠窗布局

```text
┌────────────────────────────────┐
│ 右上角：[聊天/写信] [隐藏宠窗] [设置] [!] │
│                                 │
│   ┌─────────────────────┐       │
│   │ 气泡：饿/无聊/说话…  │       │
│   └─────────────────────┘       │
│           [饰品层]              │
│         ฅ^・ﻌ・^ฅ               │
│                                 │
└────────────────────────────────┘
```

- 基础颜文字：使用当前会话所属人设的 `color` 渲染。
- 饰品层：佩戴饰品时显示在头顶；未佩戴则隐藏。
- 气泡：位于桌宠上方，临时显示 AI 说话、活动提示、错误信息，自动消失。
- 聊天/写信按钮：
  - 正常状态显示“聊天”。
  - 当前会话 AI 出门中时显示“写信”。
- 隐藏宠窗按钮：隐藏后只留下一个“显示宠窗”按钮。
- 设置按钮：打开设置窗。
- 红色感叹号：出错或休眠时显示，点击后弹出中文错误气泡。

### 3.3 主宠窗状态

- 正常：基础颜文字 + 当前人设颜色。
- 饿：显示对应表情或气泡，例如“好饿…”；颜色仍使用人设颜色。
- 无聊：显示无聊表情或气泡。
- 睡觉：显示睡觉表情；睡眠计时结束后自动唤醒，用户点击/摸摸/喂食也可唤醒。
- 吃东西：喂食后短暂显示吃东西表情。
- 说话：AI 开始回复前先切换说话表情，再显示流式气泡。
- 思考中：仅在聊天工具调用或说话前显示；记忆整合后台任务不显示思考中表情。
- 出门中：不显示出门中表情，只显示文字“`{当前人设名}出门啦`”；聊天按钮变为“写信”。
- 休眠：显示红色感叹号，不主动说话；AI 相关操作不可用。

### 3.4 左键与右键

- 左键单击：随机点击互动，触发点击类表情，并给当前会话亲密度 +1。
- 右键菜单：

```text
┌────────────┐
│ 聊天        │
│ 喂食        │
│ 摸摸        │
│ 桌宠状态    │
│ 饰品        │
│ 设置        │
│ 退出        │
└────────────┘
```

- 出门中时，“喂食”“摸摸”置灰，点击后只弹“它出门啦”。
- 喂食、摸摸成功时更新亲密度和桌宠状态。
- 退出关闭整个应用，包括所有窗口、托盘和后台任务。

## 4. 系统托盘

- 托盘图标使用应用图标。
- 左键单击托盘图标：显示或聚焦主宠窗。
- 右键菜单：

```text
┌────────────┐
│ 显示宠窗    │
│ 设置        │
│ 退出        │
└────────────┘
```

- “退出”与主宠窗右键退出行为一致，关闭整个应用。

## 5. 聊天窗

### 5.1 聊天窗布局

```text
┌──────────────────────────────────┐
│ 颜喵 YanMew    [新建] [记忆] [背景] │
│ ┌──────────────────────────────┐ │
│ │ 会话列表                      │ │
│ │ ○ 会话A  ⋯ [重命名] [删除]   │ │
│ │ ○ 会话B  ⋯ [重命名] [删除]   │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 消息气泡区                    │ │
│ │ 用户消息靠右                  │ │
│ │ AI 消息靠左                   │ │
│ │ [删除] [编辑] [重说]          │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 输入框               [发送/暂停]│ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

### 5.2 顶部与会话列表

- 标题：`颜喵 YanMew`。
- 新建会话按钮：创建当前人设下的新会话，创建时可选择绑定用户设定，也可留空。
- 记忆按钮：打开当前会话的记忆小窗。
- 背景按钮：在聊天窗内直接修改当前人设的聊天窗背景。
- 会话列表按人设隔离；切换当前人设后，历史会话列表同步切换。
- 会话标题由 AI 自动生成，用户可重命名。
- 会话可切换、继续、删除；删除需要二次确认。
- 会话可修改绑定的用户设定；绑定项在会话行右侧显示“用户设定：未绑定/名称”。

### 5.3 消息区

- 用户消息靠右，AI 消息靠左。
- AI 回复为流式输出；AI 说话前先切换桌宠表情。
- 每条消息下方提供：
  - `删除`：只删除该条消息，后续消息保留。
  - `编辑`：只修改文本，不触发重新生成；用户消息和 AI 消息都可编辑。
  - `重说`：仅当最后一条是 AI 回复时显示；重新生成对最后一条用户消息的回复，并覆盖原 AI 回复。
- 删除最后一条后，若新的最后一条是 AI 回复，则它可重说。

### 5.4 输入区

- 支持多行文本输入。
- 发送后输入框清空。
- 流式回复期间，发送按钮变为“暂停”；点击后中断当前 AI 回复。
- 暂停后输入框恢复可用，已收到的流式内容按中断点保存为 AI 消息。

### 5.5 出门中状态

- 当前会话 AI 出门中时，聊天窗不展示会话列表和消息区，只显示一个简洁状态面板。
- 状态面板文案：`{当前人设名}出门啦`，并提供“写信”按钮和“跳转邮箱”按钮。
- 主宠窗聊天按钮同步变为“写信”。

### 5.6 聊天窗背景

- 聊天窗背景按人设隔离，切换人设后跟随切换。
- 背景层位于消息气泡、会话列表和输入框下方。
- 背景效果由三部分组成：
  - 背景图片：`jpg / png / webp`，单张最大 `10MB`。
  - 透明度：`0–100%`。
  - 模糊度：`0–40px`。
- 未设置背景图时使用默认纯色背景。
- 设置入口：
  - 聊天窗顶部“背景”按钮。
  - 设置 > 全局设置 > 人设 > 对应人设卡片 > 聊天窗背景。
- 上传、预览、透明度滑块、模糊度滑块、恢复默认。

## 6. 写信界面

### 6.1 打开方式

- 主宠窗出门中时点击“写信”。
- 设置 > 桌宠与内容 > 出行 > 邮箱中点击“写信”。
- 回复某封 AI 来信时，复用写信界面并带上回复目标。

### 6.2 写信界面布局

```text
┌──────────────────────────────────┐
│ 写信给：当前会话 AI              │
│ 当前人设：人设名                 │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ 写信正文                     │ │
│ │                              │ │
│ │                              │ │
│ └──────────────────────────────┘ │
│                                  │
│ [取消] [跳转邮箱]        [发送]   │
└──────────────────────────────────┘
```

### 6.3 写信规则

- 出门中时可连续写多封。
- 每封用户来信都会得到 AI 回信。
- 回信延迟默认 `10–30` 分钟随机。
- 已回复的信不能再回，邮箱中回信按钮置灰。
- 写信和回信使用当前会话人设、记忆和记事本；AI 生成的信件内容应包含可爱颜文字。
- “跳转邮箱”按钮打开当前会话邮箱管理。

## 7. 设置窗

### 7.1 设置导航

设置窗左侧采用两级分组，不把会话与聊天记录放在设置窗。

```text
┌──────────────┬──────────────────────────┐
│ 全局设置      │                          │
│   提供商      │                          │
│   人设        │                          │
│   用户设定    │                          │
│   提醒        │                          │
│   时间与天气  │        内容区             │
│   通用        │                          │
│ 桌宠与内容    │                          │
│   桌宠状态    │                          │
│   时间与桌宠  │                          │
│   记忆        │                          │
│   出行        │                          │
│   饰品        │                          │
└──────────────┴──────────────────────────┘
```

### 7.2 提供商

- 列表展示：名称、模型、聊天当前项、记忆专用项。
- 新增/编辑字段：
  - 名称
  - base URL
  - API Key
  - 模型名
- 每个提供商有“测试连接”按钮。
- 聊天当前提供商只能启用一个。
- 记忆提供商可单独指定；未指定时默认跟随聊天提供商。

### 7.3 人设

- 人设列表按卡片排列。
- 卡片字段顺序：
  - 人设名称
  - 是否当前使用
  - 本体颜色色块
  - 自调开关（默认开启，按钮明显）
  - 最近 AI 调整时间
  - 当前人设文本
  - 初始设定文本
- 操作：
  - 切换为当前人设
  - 编辑当前人设
  - 保存为初始设定
  - 从初始设定恢复
  - 选择桌宠本体颜色
  - 设置聊天窗背景
  - 查看表情库
  - 重新生成表情库
  - 导出该人设
- 颜色选择器：预设色板 + 自定义颜色，存储为十六进制颜色。
- 聊天窗背景：上传图片、预览、透明度滑块、模糊度滑块、恢复默认。
- 创建新人设后自动生成表情库；无可用 provider 时提示稍后手动生成。
- 表情库查看以标签分组展示点击（开心/惊讶/害羞）、饿、吃东西、困、无聊、思考等分类。

### 7.4 用户设定

- 列表展示：名称、更新时间。
- 每个用户设定可新建、编辑、删除。
- 用户设定只包含名称和正文内容。
- 删除用户设定时提示：绑定它的会话不会被删除，只会变为“未绑定”。
- 每个用户设定提供“导出”；同时支持“导入用户设定”。

### 7.5 提醒

- 提醒列表显示：内容、类型、状态、触发时间、来源。
- 支持新增、编辑、删除。
- 类型：
  - 一次性
  - 每天
  - 每周
  - 每月
- 状态：
  - 未完成
  - 完成
  - 已过期
- 编辑项：时间、详情、状态、循环规则。
- 到点仅提醒一次；应用关闭期间的一次性提醒，下次启动询问补提醒或标过期。

### 7.6 时间与天气

- 定位状态：已定位 / 无权限 / 定位失败。
- 天气来源：Open-Meteo / 和风天气 / 不可用。
- 和风天气 API Key 输入框，可选；保存后不展示已保存的明文 Key。

### 7.7 通用

- 开机自启开关，默认关闭。
- 应用版本信息。
- 导入与导出入口。
- 退出应用。

### 7.8 桌宠状态

```text
┌────────────────────────────────┐
│ 当前会话：会话A                │
│ 亲密度：42 / 50                │
│ 喵币余额：30                   │
│                                │
│ [每日签到]                     │
│ ┌────────────────────────────┐ │
│ │ 石头剪刀布                  │ │
│ │ [剪刀] [石头] [布]          │ │
│ │ 今日剩余：18 次             │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- 亲密度按会话显示；聊天轮数、点击、摸摸、喂食增加亲密度。
- 喵币为全局用户级余额，删除会话不影响。
- 每日签到：本地时间每天 0 点刷新，每次随机获得 `1–10` 喵币。
- 石头剪刀布：
  - 用户选择剪刀/石头/布。
  - 系统随机出拳。
  - 赢 `+5`、输 `-4`、平局 `0`。
  - 开始前余额必须 `≥ 4`。
  - 每天最多 `20` 次。

### 7.9 时间与桌宠

- 饥饿触发时长。
- 无聊触发时长。
- 睡眠最短/最长分钟数，默认 `60–120` 分钟。
- 空闲气泡触发时长。
- 全部数值可编辑并保存。
- 空闲气泡上下文由代码层决定，不在此页面展示或选择。

### 7.10 记忆

- 短期记忆字数范围。
- 长期记忆字数范围。
- 手动合并字数范围。
- 记事本工具每次 AI 调用轮数，默认 `3`。
- 记事本长度上限，默认 `4000` 字。
- 所有字数单位为中文汉字个数。

### 7.11 出行

- 出行页不显示会话选择器，数据默认跟随最近使用的会话。
- 显示当前出行状态：在家 / 出门中。
- 显示最近旅行历史。
- 两个标签页：邮箱、伴手礼。
- 邮箱和伴手礼都按最近使用的会话加载。

### 7.12 饰品

- 当前会话饰品列表。
- 每项显示：
  - 饰品名称
  - 头顶显示文字/emoji/颜文字
  - AI 按人设口吻写的简介
  - 来源：制作 / 旅行带回
  - 是否佩戴
- 操作：
  - 佩戴
  - 卸载
  - 卖出未佩戴饰品，固定获得 `10` 喵币
  - 删除未佩戴饰品
- 删除后不可恢复；卖出和删除都需要二次确认。
- AI 发起制作请求时，在主宠窗弹出确认气泡/卡片：
  - `给你买`
  - `没有钱了`
- 余额足够才可完成制作。

### 7.13 导入与导出

- 入口：全局设置 > 通用 > 导入与导出。
- 导出类型：
  - 全量备份
  - 人设资料包（分享用）
  - 人设完整包（迁移用）
  - 指定会话
  - 指定用户设定
- 导出时弹窗选择保存位置和导出范围。
- 导入时选择 `.yanmew-backup.zip`，先显示文件摘要：
  - 类型、导出时间、包含的人设/会话/用户设定/文件数量。
  - 人设资料包只包含人设定义、聊天窗背景和表情库，不包含会话与私密数据。
- 导入模式：
  - 新建副本（默认）
  - 人设资料包只允许新建副本，名称冲突时自动重命名
  - 其他备份包可选覆盖同名项（二次确认）
- 导入完成后显示成功摘要，并提示重新填写 API Key / 和风天气 API Key。
- 导入文件损坏、版本不兼容、结构异常时显示中文错误，不写入半成品数据。

```text
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ 记事本                     │ │
│ │ [大段文本，可编辑]         │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- 从聊天窗打开，自动跟随聊天窗当前会话。
- 短期记忆和长期记忆可手动编辑、删除。
- 不支持手动新建，不支持 AI 重写。
- 长期记忆选中连续几条后可合并。
- 合并前弹预览，用户可手动修改，确认后才替换。
- 旅行总结生成的短期记忆带“旅行”来源标记。

## 9. 出行管理

### 9.1 邮箱

- 邮箱列表显示：发送方、信件摘要、时间、是否已读、是否收藏。
- 支持查看、收藏、删除、回信。
- 已回复的信不能再回。
- 写信入口可打开写信界面；写信界面提供“跳转邮箱”。

### 9.2 伴手礼

- 只保存普通文字礼物。
- 每项显示文字礼物内容和 AI 按人设口吻写的备注。
- 支持查看、收藏、删除。
- 不做背包、数量、容量或使用机制。
- 旅行带回的可佩戴饰品进入“饰品管理”，不进入伴手礼。

### 9.3 出行历史

```text
┌────────────────────────────────┐
│ 出行历史                      │
│ ┌────────────────────────────┐ │
│ │ 出发时间：2026-09-08 14:00 │ │
│ │ 返回时间：2026-09-08 16:20 │ │
│ │ 带回：普通文字礼物          │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- 展示最近旅行记录。
- 可查看出发时间、计划返回时间、实际返回时间和带回结果。

## 10. 错误、空态与加载

### 10.1 错误

- 主宠窗显示红色 `!` 感叹号。
- 点击感叹号弹出中文错误气泡。
- 错误类型包括：无 Token、连接失败、限流、后台记忆整合失败、导入导出失败等。
- 休眠状态下 AI 不主动说话，AI 相关操作不可用。
- 后台记忆整合失败、导入导出失败只提示，不进入休眠；主流程 API 不可用时才进入休眠。

### 10.2 空态

- 未配置提供商：聊天窗提示“请先在设置中添加 API 提供商”。
- 未配置人设：使用默认“喵喵桌宠”，设置页提示用户配置。
- 无会话：聊天窗显示“新建一个会话开始聊天”。
- 无信件：邮箱显示“还没有信件”。
- 无伴手礼：伴手礼显示“还没有收到伴手礼”。
- 无饰品：饰品管理显示“还没有饰品”。

### 10.3 加载

- 流式回复：AI 气泡持续追加文字，不显示全局 loading。
- 流式回复期间发送按钮显示“暂停”。
- 生成表情库：按钮显示“生成中…”。
- 测试连接：按钮显示“测试中…”。
- 记忆合并：合并按钮显示“合并中…”。
- 旅行总结在后台生成，不阻塞返回结果。
- 导入/导出打包或校验：按钮显示“处理中…”，期间禁用重复点击。

## 12. 关键交互流程

### 12.1 正常聊天

1. 用户点击主宠窗“聊天”。
2. 打开聊天窗，选择或新建会话。
3. 用户输入并发送。
4. AI 先切换表情，再流式输出回复。
5. 流式期间发送按钮变为“暂停”，点击可中断。
6. 回复完成后后台检查记忆整合、记事本工具和人设自调。

### 12.2 AI 出门

1. 满足在线时间和空闲条件后，主宠窗弹出“我出去玩啦”。
2. 主宠窗只显示“`{当前人设名}出门啦`”，不展示出门中表情。
3. 聊天按钮变成“写信”，聊天窗只显示写信入口。
4. 用户写信后等待 `10–30` 分钟随机回信。
5. AI 回来时带回伴手礼，并生成旅行总结短期记忆。

### 12.3 制作饰品

1. AI 达到亲密度档位并发起制作请求。
2. 主宠窗弹出确认：`给你买` / `没有钱了`。
3. 用户确认且余额足够，扣喵币并生成饰品。
4. 饰品进入饰品管理，用户可佩戴、卸载、卖出或删除。

### 12.4 从聊天创建提醒

1. 用户在聊天中要求提醒。
2. AI 通过 function calling 创建结构化提醒。
3. 设置 > 全局设置 > 提醒中出现该提醒，可手动编辑时间、详情、状态。

### 12.5 导入与导出

1. 用户打开设置 > 全局设置 > 通用 > 导入与导出。
2. 选择导出范围，Rust 打包 zip 并保存到用户选择的位置。
3. 用户换机或备份后，在目标机器选择导入文件。
4. 前端显示摘要，用户选择“新建副本”或“覆盖同名项”。
5. Rust 校验并导入；完成后提示重新填写 API Key / 和风天气 API Key。

## 13. 前端与 Rust 接口约定

- 所有数据通过 Tauri command 获取或提交。
- AI 流式输出通过 Tauri event 推送到前端；前端可调用中断命令停止当前回复。
- 前端不直接读写 SQLite，不直接调用 AI 提供商。
- API Key 只在设置表单输入，前端不展示已保存的明文 Key。
- 前端统一处理错误事件，映射为红色感叹号和中文错误气泡。
- 前端只展示当前会话的出行、信件、伴手礼、饰品和记忆数据。
- 所有删除操作使用确认弹窗；删除会话、人设、饰品等不可恢复操作需要二次确认。
