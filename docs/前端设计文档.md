# 颜喵 YanMew 前端设计文档

- 日期：2026-09-15
- 类型：前端界面与交互设计
- 状态：已确认方案已同步
- 说明：本文描述界面结构、视觉层次和交互；保存与恢复规则见 `docs/数据库与持久化设计.md`。

## 1. 设计目标与原则

- 仅面向 Windows，视觉上像桌面小宠物，不做传统后台管理系统。
- 主宠窗保持小、透明、无边框、置顶；聊天窗轻气泡风；设置窗使用圆角卡片，但整体仍要轻。
- 颜文字是核心视觉元素，字体要大、清晰；状态优先用颜文字和短气泡表达。
- 桌宠本体颜色按人设绑定，只影响基础颜文字；饰品层、气泡、窗口背景不跟随该颜色。
- 所有错误统一为红色感叹号，点击后显示中文错误气泡，不弹系统风格报错页。
- v1 不引入图片素材型饰品、旅行礼物或桌宠形象；饰品和礼物全部用文字、颜文字或 emoji 表达。
- 文案使用简体中文；代码、路径、配置键保持原文。

## 3. 主宠窗

### 3.1 画布

- 默认大小：`320×240`。
- 默认位置：屏幕右下角；用户拖动后记住位置，下次启动恢复。
- 窗口透明、无边框、置顶。
- 透明空白区域鼠标点击穿透，只让颜文字本体和可交互控件接收鼠标事件。
- 隐藏宠窗后，窗口缩小为只保留“显示宠窗”按钮；点击该按钮恢复完整宠窗。
- 固定宠窗内只移动颜文字及其饰品、气泡，不自动移动窗口；仅在画布有可用位置时避开前台窗口，鼠标靠近画布时可在范围内靠近。拖动、点击、聊天、睡觉、出门中、隐藏宠窗时暂停。

### 3.2 主宠窗布局

```text
┌────────────────────────────────┐
│ 右上角：[聊天/写信] [隐藏宠窗] [设置] [!] │
│                                 │
│   ┌─────────────────────┐       │
│   │ 气泡：饿/无聊/说话…  │       │
│   └─────────────────────┘       │
│           [饰品层]              │
│         ฅ^・ﻌ・^ฅ               │
│                                 │
└────────────────────────────────┘
```

- 基础颜文字：使用当前会话所属人设的 `color` 渲染。
- 饰品层：佩戴饰品时显示在头顶；未佩戴则隐藏。
- 气泡：位于桌宠上方，临时显示 AI 说话、活动提示、错误信息，自动消失。
- 聊天/写信按钮：
  - 正常状态显示“聊天”。
  - 当前会话 AI 出门中时显示“写信”。
- 隐藏宠窗按钮：隐藏后只留下一个“显示宠窗”按钮。
- 设置按钮：打开设置窗。
- 红色感叹号：出错或休眠时显示，点击弹出中文错误气泡；休眠错误气泡提供“刷新”恢复入口，设置与测试连接始终可用。

### 3.3 主宠窗状态

- 正常：基础颜文字 + 当前人设颜色。
- 饿：显示对应表情或气泡，例如“好饿…”；颜色仍使用人设颜色。
- 无聊：显示无聊表情，并可能按概率主动发一条消息气泡。
- 睡觉：显示睡觉表情；睡眠计时结束后自动唤醒，用户点击/摸摸/喂食也可唤醒。
- 吃东西：喂食后短暂显示吃东西表情。
- 说话：AI 开始回复前先切换说话表情，再显示流式气泡。
- 思考中：仅在聊天工具调用或说话前显示；记忆整合后台任务不显示思考中表情。
- 出门中：不显示出门中表情，只显示文字“`{当前人设名}出门啦`”；聊天按钮变为“写信”。
- 休眠：显示红色感叹号，不主动说话；AI 相关操作不可用。

### 3.4 左键与右键

- 左键单击：随机点击互动，触发点击类表情，并给当前会话亲密度 +1。
- 右键菜单：

```text
┌────────────┐
│ 聊天        │
│ 喂食        │
│ 摸摸        │
│ 桌宠状态    │
│ 饰品        │
│ 设置        │
│ 退出        │
└────────────┘
```

- 出门中时，“喂食”“摸摸”置灰，点击后只弹“它出门啦”。
- 喂食、摸摸成功时更新亲密度和桌宠状态。
- 退出关闭整个应用，包括所有窗口、托盘和后台任务。

## 4. 系统托盘

- 托盘图标使用应用图标。
- 左键单击托盘图标：显示或聚焦主宠窗。
- 右键菜单：

```text
┌────────────┐
│ 显示宠窗    │
│ 设置        │
│ 退出        │
└────────────┘
```

- “退出”与主宠窗右键退出行为一致，关闭整个应用。

## 5. 聊天窗

### 5.1 聊天窗布局

```text
┌──────────────────────────────────┐
│ 颜喵 YanMew    [新建] [记忆] [背景] │
│ ┌──────────────────────────────┐ │
│ │ 会话列表                      │ │
│ │ ○ 会话A  ⋯ [重命名] [删除]   │ │
│ │ ○ 会话B  ⋯ [重命名] [删除]   │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 消息气泡区                    │ │
│ │ 用户消息靠右                  │ │
│ │ AI 消息靠左                   │ │
│ │ [删除] [编辑] [重说]          │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 输入框               [发送/暂停]│ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

### 5.2 顶部与会话列表

- 标题：`颜喵 YanMew`。
- 新建会话按钮：创建当前人设下的新会话，创建时可选择绑定用户设定，也可留空。
- 记忆按钮：打开当前会话的记忆小窗。
- 背景按钮：在聊天窗内直接修改当前人设的聊天窗背景。
- 会话列表按人设隔离；切换当前人设后，历史会话列表同步切换。
- 会话标题由 AI 自动生成，用户可重命名。
- 会话可切换、继续、删除；删除需要二次确认。切换会话/人设时取消原会话旅行及待回信，不生成返回结果；有进行中旅行时在切换操作旁说明该后果。
- 切换/删除会话前中断流式请求，前端不把旧请求事件显示到新会话。
- 会话可修改绑定的用户设定；绑定项在会话行右侧显示“用户设定：未绑定/名称”。

### 5.3 消息区

- 用户消息靠右，AI 消息靠左。
- AI 回复为流式输出；AI 说话前先切换桌宠表情。
- 用户和 AI 的历史消息都提供 `编辑`：只修改消息原文，不自动修改或删除短期记忆、长期记忆和旅行游记；需要同步时由用户进入记忆小窗操作。
- 只有最底部的完整回合提供 `删除本轮`：按钮显示在该轮 AI 回复下方，删除时同时删除本轮用户消息、AI 回复、对应短期记忆，并按触发关系回退长期记忆。
- 如果最底部只有一条尚未得到正常回复的用户消息，该消息提供 `删除`，删除未完整回合。
- `重说` 只在最后一个完整回合的 AI 回复上显示；成功后原位更新 AI 回复与本轮短期记忆，如果该短期记忆参与了长期记忆，则同步重新生成受影响长期记忆；失败或中断保留旧结果。

### 5.4 输入区

- 支持多行文本输入。
- 发送后输入框清空。
- 流式回复期间，发送按钮变为“暂停”；点击后中断当前 AI 回复。
- 暂停后输入框恢复可用，已收到正文保存一次，无正文不插空消息；中断不增加完整聊天轮次亲密度。已提交工具操作不回滚。消息统一由 Rust 保存。

### 5.5 出门中状态

- 当前会话 AI 出门中时，聊天窗不展示会话列表和消息区，只显示一个简洁状态面板。
- 出门状态面板保留切换其他会话的入口，并说明切换将取消本次旅行和待回信。
- 状态面板文案：`{当前人设名}出门啦`，并提供“写信”按钮和“跳转邮箱”按钮。
- 主宠窗聊天按钮同步变为“写信”。

### 5.6 聊天窗背景

- 聊天窗背景按人设隔离，切换人设后跟随切换。
- 背景层位于消息气泡、会话列表和输入框下方。
- 背景效果由三部分组成：
  - 背景图片：`jpg / png / webp`，单张最大 `10MB`。
  - 透明度：`0–100%`。
  - 模糊度：`0–40px`。
- 未设置背景图时使用默认纯色背景。
- 设置入口：
  - 聊天窗顶部“背景”按钮。
  - 设置 > 全局设置 > 人设 > 对应人设卡片 > 聊天窗背景。
- 上传、预览、透明度滑块、模糊度滑块、恢复默认。

## 6. 写信界面

### 6.1 打开方式

- 主宠窗出门中时点击“写信”。
- 旅行进行中，在设置 > 桌宠与内容 > 出行 > 邮箱点击“写信”；返回后入口置灰。
- 回复某封 AI 来信时，复用写信界面并带上回复目标。

### 6.2 写信界面布局

```text
┌──────────────────────────────────┐
│ 写信给：当前会话 AI              │
│ 当前人设：人设名                 │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ 写信正文                     │ │
│ │                              │ │
│ │                              │ │
│ └──────────────────────────────┘ │
│                                  │
│ [取消] [跳转邮箱]        [发送]   │
└──────────────────────────────────┘
```

### 6.3 写信规则

- 出门中时可连续写多封。
- 旅行仍在进行且信件未取消时，每封用户来信按计划获得 AI 回信；返回或切换会话后取消待回信。
- 回信延迟默认 `10–30` 分钟随机。
- 已回复的信不能再回，删除回复也不恢复资格；旅行返回后禁止写信和回信，邮箱中相应按钮置灰。
- 写信和回信使用当前会话人设、记忆和记事本；AI 生成的信件内容应包含可爱颜文字。
- “跳转邮箱”按钮打开当前会话邮箱管理。

## 7. 设置窗

### 7.1 设置导航

设置窗左侧采用两级分组，不把会话与聊天记录放在设置窗。

```text
┌──────────────┬──────────────────────────┐
│ 全局设置      │                          │
│   提供商      │                          │
│   人设        │                          │
│   用户设定    │                          │
│   提醒        │                          │
│   时间与天气  │        内容区             │
│   记忆        │                          │
│   通用        │                          │
│ 桌宠与内容    │                          │
│   桌宠状态    │                          │
│   时间与桌宠  │                          │
│   出行        │                          │
│   饰品        │                          │
│   节日        │                          │
└──────────────┴──────────────────────────┘
```

### 7.2 提供商

页面分为“聊天与记忆整合模型”和“Embedding 模型”两个模块。

- 聊天与记忆整合列表展示：名称、模型、聊天当前项、记忆专用项。
- 新增/编辑字段：
  - 名称
  - base URL
  - API Key
  - 模型名
- 每个提供商可编辑名称、base URL、模型和密钥，并有“测试连接”按钮；密钥留空表示保持原值，清除密钥使用独立操作。
- 当前聊天提供商配置有效或测试成功时可解除休眠。
- 聊天当前提供商只能启用一个。
- 记忆提供商可单独指定；提供“跟随聊天提供商”选项以清除独立选择。
- Embedding 模型默认显示并启用内置本地 `BAAI/bge-small-zh-v1.5`，标记“随应用提供 · 离线可用”；本地项无需 base URL 或 API Key，不能编辑或删除。
- 用户可新增联网 Embedding 提供商，每项填写名称、base URL、API Key 和模型名，调用 OpenAI-compatible `/embeddings` 接口。
- Embedding 卡片显示类型（本地/联网）、模型名与当前状态，并提供“设为当前”和“测试连接”；联网项还可编辑和删除。
- 测试本地项时执行一次本地向量生成并校验维度；测试联网项时发送最小文本并校验响应包含有效向量。
- 切换当前 Embedding 后提示“正在后台重建长期记忆检索索引”；重建期间仍可聊天和使用关键词检索。
- 联网 Embedding 失败时提示“语义检索暂不可用，已使用关键词检索”，不让桌宠进入休眠。

### 7.3 人设

- 人设列表按卡片排列。
- 卡片字段顺序：
  - 人设名称
  - 是否当前使用
  - 本体颜色色块
  - 自调开关（默认开启，按钮明显）
  - 最近 AI 调整时间
  - 当前人设文本
  - 初始设定文本
- 操作：
  - 切换为当前人设
  - 编辑当前人设
  - 保存为初始设定
  - 从初始设定恢复
  - 选择桌宠本体颜色
  - 设置聊天窗背景
  - 查看表情库
  - 重新生成表情库
  - 导出该人设
- 颜色选择器：预设色板 + 自定义颜色，存储为十六进制颜色。
- 聊天窗背景：上传图片、预览、透明度滑块、模糊度滑块、恢复默认。
- 创建新人设后自动生成表情库；无可用 provider 时提示稍后手动生成。
- 表情库查看以标签分组展示点击（开心/惊讶/害羞）、饿、吃东西、困、无聊、思考等分类。

### 7.4 用户设定

- 列表展示：名称、更新时间。
- 每个用户设定可新建、编辑、删除。
- 用户设定只包含名称和正文内容。
- 删除用户设定时提示：绑定它的会话不会被删除，只会变为“未绑定”。
- 每个用户设定提供“导出”；同时支持“导入用户设定”。

### 7.5 提醒

- 提醒列表显示：内容、类型、状态、触发时间、来源。
- 支持新增、编辑、删除。
- 类型：
  - 一次性
  - 每天
  - 每周
  - 每月
- 状态：
  - 未完成
  - 完成
  - 已过期
- 编辑项：时间、详情、循环规则影响未来触发；完成/过期操作本次触发记录。重复提醒“完成”仅完成本次，继续下一次；永久停止只能删除提醒。
- 显示本次原定时间与下一次触发时间；错过的一次性提醒保留“补提醒/标过期”，未选择就退出时下次继续显示。
- 到点仅提醒一次；应用关闭期间的一次性提醒，下次启动询问补提醒或标过期。

### 7.6 时间与天气

- 定位状态：已定位 / 无权限 / 定位失败。
- 天气来源：Open-Meteo / 和风天气 / 不可用。
- 和风天气 API Key 输入框，可选；保存后不展示已保存的明文 Key。

### 7.7 通用

- 开机自启开关，默认关闭。
- 应用版本信息。
- 导入与导出入口。
- 退出应用。

### 7.8 桌宠状态

```text
┌────────────────────────────────┐
│ 当前会话：会话A                │
│ 亲密度：42 / 50                │
│ 喵币余额：30                   │
│                                │
│ [每日签到]                     │
│ ┌────────────────────────────┐ │
│ │ 石头剪刀布                  │ │
│ │ [剪刀] [石头] [布]          │ │
│ │ 今日剩余：18 次             │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- 亲密度按会话显示；聊天轮数、点击、摸摸、喂食增加亲密度。
- 喵币为全局用户级余额，删除会话不影响。
- 每日签到：本地时间每天 0 点刷新，无节日时随机获得 `1–10` 喵币；当天命中节日时固定 `10` 喵币，并展示节日祝福词。
- 这是颜喵应用唯一的全局签到，入口只在“桌宠状态”；游戏中心和小游戏插件不显示另一套签到。
- 石头剪刀布：
  - 用户选择剪刀/石头/布。
  - 系统随机出拳。
  - 赢 `+5`、输 `-4`、平局 `0`。
  - 开始前余额必须 `≥ 4`。
  - 每天最多 `20` 次。
- 石头剪刀布是随便携版提供的第一方插件，从统一游戏中心启动，与本地安装插件使用相同的宿主、游戏局和钱包接口。

### 7.8.1 游戏中心与插件管理

- 第一版展示随应用提供和用户从本地安装的插件，支持从 `.yanmew-game` 安装、启用、停用、更新、卸载、存档处理和权限管理。
- 石头剪刀布标记为“随应用提供”，允许停用和清除私有存档，不允许永久卸载；应用升级时随颜喵一起更新。
- 本地插件申请“修改喵币”时，安装确认页单独展示该权限及“可以增加或扣除全局喵币”的说明；随包插件在第一次打开时显示同等权限确认。用户允许或拒绝，拒绝后仍可纯玩。
- 用户可以在游戏管理页撤销喵币权限。插件更新增加新权限时必须再次确认，不能静默沿用旧授权。
- 每个插件显示名称、作者、版本、来源、源码链接、存档作用域和权限。第一版不显示“官方收录”或其他推荐徽标。
- 第一版不直接连接 GitHub。以后社区仓库启用后，用户先在浏览器下载，再从本地安装；GitHub 自动安装、插件网站和 `yanmew://install?...` 放到后续版本。
- 小游戏不显示或申请 AI 出题、AI 解说能力，插件协议不提供 `ai.generate()`。
- 完整协议与版本范围见 `docs/小游戏插件生态设计.md`。

- 全部数值可编辑并保存。

- 长期记忆字数范围。

- 进入上下文的最近消息原文数量，默认 `30`。

### 7.11 出行

- 显示当前出行状态：在家 / 出门中。
- 显示最近旅行历史，历史状态区分出门中、已返回和已取消；取消不显示虚构返回礼物或游记。
- 三个标签页：邮箱、伴手礼、旅行游记。
- 邮箱、伴手礼和旅行游记都按当前会话加载。

### 7.12 饰品

- 当前会话饰品列表。
- 每项显示：
  - 饰品名称
  - 头顶显示文字/emoji/颜文字
  - AI 按人设口吻写的简介
  - 来源：制作 / 旅行带回
  - 是否佩戴
- 操作：
  - 佩戴
  - 卸载
  - 卖出未佩戴饰品，固定获得 `10` 喵币
  - 删除未佩戴饰品
- 删除后不可恢复；卖出和删除都需要二次确认。
- AI 发起制作请求时，在主宠窗弹出确认气泡/卡片：
  - `给你买`
  - `没有钱了`
- 余额足够才可完成制作。

### 7.13 节日

- 页面分“系统节日”和“我的节日”两部分。
- 系统节日（母表）：只读列表，显示节日名、历法类型（公历/农历/节气）、公历月日、农历月日、祝福词、是否纪念性节日。
- 我的节日（当前会话子表）：显示名称、类型（节日/生日/纪念日/自定义）、历法类型、公历月日、农历月日、祝福词、备注、来源。
- 支持手动新增、编辑、删除；农历日期可选择“闰月”，祝福词必填。year 记录本年，日期按内置小型日历判断，本年无对应日期则不触发。
- 页面不显示会话选择器，数据跟随当前会话，与出行页一致。
- 页面提示：农历与节气日期每年自动查内置表更新，无需手动维护。
- 母表只读，不提供编辑入口。

### 7.14 导入与导出

- 入口：全局设置 > 通用 > 导入与导出。
- 导出类型：
  - 全量备份
  - 人设资料包（分享用）
  - 人设完整包（迁移用）
  - 指定会话
  - 指定用户设定（可选择同时导出绑定它的会话）
- 导出时弹窗选择保存位置和导出范围。
- 导入时选择 `.yanmew-backup.zip`，先显示文件摘要：
  - 类型、导出时间、包含的人设/会话/用户设定/文件数量。
  - 人设资料包只包含人设定义、聊天窗背景和表情库，不包含会话与私密数据。
- 导入模式：
  - 新建副本（默认）
  - 人设资料包只允许新建副本，名称冲突时自动重命名
  - 其他备份包可选覆盖同名项（二次确认）
- 全量导入摘要明确显示：备份将替换全局喵币、账单、设置、提醒与提供商非密钥配置，不累加余额；部分包不修改这些全局数据。
- 全量备份与恢复同时显示小游戏插件登记、权限、设置、私有存档和游戏局；石头剪刀布程序包由目标便携版提供。用户另装的插件程序包是否随备份携带，在插件开发阶段确定后再补充对应提示。
- 覆盖同名项列出对象类型、父级和目标供明确选择，不自动覆盖多个同名对象。
- 导入完成显示成功摘要；仅对需要配置的密钥提示重新填写，部分包不清除目标现有密钥。
- 长期记忆全文索引和向量不从备份导入；导入提交后显示“正在重建长期记忆检索索引”，该过程不阻塞已导入数据的查看。
- 导入文件损坏、版本不兼容、结构异常时显示中文错误，不写入半成品数据。

## 8. 记忆小窗

```text
┌────────────────────────────────┐
│ 当前会话记忆                    │
│ ┌────────────────────────────┐ │
│ │ 短期记忆                   │ │
│ │ - 记忆1 [编辑] [重新生成]  │ │
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ 长期记忆                   │ │
│ │ - 记忆A [编辑] [重新整合]  │ │
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ 记事本                     │ │
│ │ [大段文本，可编辑]         │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- 从聊天窗打开，自动跟随聊天窗当前会话。
- 短期记忆按聊天回合展示来源回合与“尚未整合/已经整合”状态；长期记忆卡片优先显示简短标题，展开后显示正文、来源短期记忆、覆盖到的消息和触发回合。
- **短期记忆和长期记忆是中性事实记录，不使用人设口吻，不需要任何氛围总结或主观评价，必须只是如同剧本一样的叙事描述。**
- 短期记忆和长期记忆都不支持手动新建或删除，只支持手动编辑；长期记忆的标题和正文均可编辑。
- 短期记忆提供“重新生成”，使用绑定回合原文生成；长期记忆提供“重新整合”，只使用其原有短期记忆来源，并同时生成标题和正文。生成后先弹出可编辑预览，用户确认才覆盖原记录，ID 不变。
- 编辑或重新生成已整合短期记忆时提示：现有长期记忆不会自动变化，可按需重新整合相关长期记忆。
- 不提供“选择多条长期记忆合并”。长期记忆正常保存时不自动删除、再次合并或压缩，进入上下文的数量由最近 `m` 条与混合 RAG 控制。
- 长期记忆编辑或重新整合成功后，全文索引同步更新，旧向量失效并在后台补建；向量尚未补建时仍可使用标题与正文进行关键词检索。
- 旅行游记不出现在记忆小窗，统一在出行管理中查看。

```text

│ 出行历史                      │
│ ┌────────────────────────────┐ │
```

## 10. 错误、空态与加载

### 10.1 错误

- 主宠窗显示红色 `!` 感叹号。
- 点击感叹号弹出中文错误气泡。
- 错误类型包括：无 Token、连接失败、限流、后台记忆整合失败、导入导出失败等。
- 休眠状态下 AI 不主动说话，普通 AI 操作不可用；“刷新”、设置、测试连接仍可用。刷新恢复尝试、配置有效提供商或当前聊天提供商测试成功可恢复；失败保留错误。
- 后台记忆整合失败、导入导出失败只提示，不进入休眠；主流程 API 不可用时才进入休眠。

### 10.2 空态

- 未配置提供商：聊天窗提示“请先在设置中添加 API 提供商”。
- 未配置人设：使用默认“喵喵桌宠”，设置页提示用户配置。
- 无会话：聊天窗显示“新建一个会话开始聊天”。
- 无信件：邮箱显示“还没有信件”。
- 无伴手礼：伴手礼显示“还没有收到伴手礼”。
- 无饰品：饰品管理显示“还没有饰品”。
- 无节日：我的节日列表显示“还没有添加节日”。

### 10.3 加载

- 流式回复：AI 气泡持续追加文字，不显示全局 loading。
- 流式回复期间发送按钮显示“暂停”。
- 生成表情库：按钮显示“生成中…”。
- 测试连接：按钮显示“测试中…”。
- 记忆重新生成/重新整合：对应按钮显示“生成中…”或“整合中…”。
- 旅行游记在后台生成，不阻塞返回结果。
- 导入/导出打包或校验：按钮显示“处理中…”，期间禁用重复点击。

## 12. 关键交互流程

### 12.1 正常聊天

1. 用户点击主宠窗“聊天”。
2. 打开聊天窗，选择或新建会话。
3. 用户输入并发送。
4. AI 先切换表情，再流式输出回复。
5. 流式期间发送按钮变为“暂停”，点击可中断。
6. Rust 保存回复后后台检查记忆整合与人设自调；记事本工具在聊天工具循环中执行。

### 12.2 AI 出门

1. 满足在线时间和空闲条件后，主宠窗弹出“我出去玩啦”。
2. 主宠窗只显示“`{当前人设名}出门啦`”，不展示出门中表情。
3. 聊天按钮变成“写信”，聊天窗只显示写信入口。
4. 用户写信后等待 `10–30` 分钟随机回信。
5. AI 回来时生成 1 封回来信、带回伴手礼，并在结果保存后生成 1 篇会话级旅行游记。

### 12.3 制作饰品

1. AI 达到亲密度档位并发起制作请求。
2. 主宠窗弹出确认：`给你买` / `没有钱了`。
3. 用户确认且余额足够，扣喵币并生成饰品。
4. 饰品进入饰品管理，用户可佩戴、卸载、卖出或删除。

### 12.4 从聊天创建提醒

1. 用户在聊天中要求提醒。
2. AI 通过 function calling 创建结构化提醒。
3. 设置 > 全局设置 > 提醒中出现该提醒，可手动编辑时间、详情、状态。

### 12.5 导入与导出

1. 用户打开设置 > 全局设置 > 通用 > 导入与导出。
2. 选择导出范围，Rust 打包 zip 并保存到用户选择的位置。
3. 用户换机或备份后，在目标机器选择导入文件。
4. 前端显示摘要，用户选择“新建副本”或“覆盖同名项”。
5. Rust 校验并导入；完成后提示重新填写 API Key / 和风天气 API Key。

### 12.6 签到彩蛋

1. 用户点击“每日签到”。
2. Rust 查当天是否命中母表或子表节日。
3. 命中：固定发放 `10` 喵币，直接展示节日记录里的祝福词，不调用 AI。
4. 同时命中母表和子表：合并祝福词，喵币仍为 `10`。
5. 未命中：随机发放 `1–10` 喵币。
6. 当天是节日时，聊天上下文的日期信息包含节日名称。

### 12.7 无聊主动消息与桌面游走

1. 长时间无互动后桌宠进入无聊状态。
2. 后台任务按概率用当前会话或该人设最近会话的人设、记忆与环境生成一条气泡。
3. 休眠、出门中、隐藏宠窗或正在聊天时不触发。
4. 只在固定画布内移动颜文字及饰品、气泡；不移动整个窗口。日常聊天与主动消息共用含当天节日母子表的上下文。
5. 用户拖动、点击、打开聊天、睡觉、出门中、隐藏宠窗时立即暂停游走。

## 13. 前端与 Rust 接口约定

- 所有数据通过 Tauri command 获取或提交。
- AI 流式输出通过 Tauri event 推送到前端；前端可调用中断命令停止当前回复。
- 前端不直接读写 SQLite，不直接调用 AI 提供商。
- API Key 只在设置表单输入，前端不展示已保存的明文 Key。
- 前端统一处理错误事件，映射为红色感叹号和中文错误气泡。
- 前端只展示当前会话的出行、信件、伴手礼、饰品、节日子表和记忆数据。
- 所有删除操作使用确认弹窗；删除会话、人设、饰品等不可恢复操作需要二次确认。
