# 颜文字桌宠（Windows 桌面宠物）设计文档

- 日期：2026-09-04
- 状态：已确认，待进入实现计划
- 平台：仅 Windows
- 技术栈：Tauri 2（Rust 核心）+ React + TypeScript 前端

## 1. 目标

做一个常驻 Windows 桌面的颜文字桌宠：透明、置顶、可拖动的可爱小窗口，形象全部用颜文字。它能根据用户设置的人设做出不同表情和动作，能与用户聊天、提醒用户，并感知时间、地点、天气。

## 2. 功能需求

### 2.1 窗口与外观
- 主宠窗：透明、无边框、置顶；默认位于屏幕一个小区域；可拖动到任意位置。
- 透明空白区域鼠标点击穿透，只让颜文字本身可交互。
- 聊天窗：独立、轻量、贴近气泡风格的窗口，可拖动、可关闭。
- 设置窗：常规窗口，承载所有配置。
- 系统托盘图标：快速打开设置、退出应用。

### 2.2 设置
- API 提供商：可添加多个，每项包含 名称、base URL（自定义接口时）、API Key、模型名；可设置一个为当前启用；可随时切换。
- 人设：可保存多个人设（prompt），可切换当前人设。
- 时间参数：饥饿时长、无聊时长、多久没点击进入睡觉、空闲自动气泡时长，全部可配置。

### 2.3 宠物活动与表情
- 活动：点击互动、移动（拖动）、饿、吃东西、无聊、睡觉、说话、思考中、休眠（错误）。
- 表情来源：
  - 设定或切换人设后，AI 分析人设，一次性生成分类表情库并保存。
  - 表情分类：开心、惊讶、害羞、饿、困、无聊、思考等；不同活动取对应标签，点击在点击类表情中随机。
  - 每次说话（聊天回复）由 AI 实时重新生成表情，说话前先切换，不取表情库。

### 2.4 互动方式
- 左键单击：随机点击互动。
- 右键：菜单（聊天、喂食、摸摸、设置、退出等）。

### 2.5 聊天
- 点击聊天按钮打开轻量聊天窗。
- 回复为流式输出；AI 说话前先切换表情。
- 聊天记录持久化，可在设置中查看。
- 支持新建会话；可查看、切换、继续历史会话。
- 会话按人设隔离：切换人设后历史会话列表随之切换。

### 2.6 空闲气泡
- 长时间没点击时，AI 按当前人设现场生成一条消息气泡。
- 触发时长用户可配置。

### 2.7 错误与休眠
- 无 token、无法连接 API 等异常时进入休眠状态。
- 出现错误显示红色感叹号；点击后显示中文错误提示。

### 2.8 环境感知
- 时间：由系统提供。
- 地点：Windows 系统定位自动获取，处理定位权限。
- 天气：Open-Meteo（免费、按经纬度）；若国内不可直连，用和风天气免费版兜底。

### 2.9 提醒
- 来源：聊天中让 AI 提取并创建；设置中手动创建。
- 类型：一次性、重复（每天/每周/每月，循环规则可配置）；创建时可选类型和循环方式。
- 到点时应用开着：以 AI 人设语气弹气泡提醒，可标记完成。
- 到点时应用未开：下次打开询问“补提醒还是标过期”。
- 状态：未完成、完成、已过期。

### 2.10 v1 不做
- 联网搜索（留待后续迭代）。

## 3. 技术架构

- 桌面壳：Tauri 2（Rust 核心）+ React + TypeScript 前端。
- Rust 核心模块：
  - 配置存储
  - API 提供商管理
  - 人设管理
  - 表情库管理
  - AI 客户端（官方 OpenAI + 自定义 OpenAI 兼容接口）
  - 宠物状态机
  - 提醒调度
  - 天气与定位服务
  - 聊天会话存储
- 本地数据：SQLite。
- 安全：API Key 使用 Windows DPAPI 加密存储。

## 4. 数据模型

- `providers`：id、名称、base_url、api_key（加密）、model、is_active。
- `personas`：id、名称、prompt、is_active、表情库（JSON，按标签分类）。
- `sessions`：id、persona_id、标题、created_at、updated_at。
- `messages`：id、session_id、role、content、expression、created_at。
- `reminders`：id、类型（一次性/重复）、循环规则、content、状态（未完成/完成/已过期）、触发时间、来源（聊天/手动）。
- `settings`：饥饿时长、无聊时长、睡觉等待时长、空闲气泡时长等。

## 5. AI 引擎

- Provider 抽象统一流式协议：官方 OpenAI 与自定义 OpenAI 兼容接口共用一套流式客户端。
- 人设初始化：设定/切换人设后调用 AI 分析人设，生成分类表情库。
- 聊天回复两步走：
  1. 先请求 AI 快速决定本次说话表情；
  2. 前端立即切换表情；
  3. 再流式输出正文。
- 空闲气泡：每次按人设现场生成。
- 错误处理：无 key、连不上、限流等统一进入休眠状态，展示红色感叹号与中文错误。

## 6. 宠物状态机

- 状态：正常、饿、无聊、睡觉、吃东西、说话、思考中、休眠。
- 饿/无聊/睡觉由可配置时长触发；喂食/摸摸/点击切到对应状态。
- 表情：点击类随机取点击标签；饿/无聊/睡觉取对应标签；说话用实时生成表情。

## 7. 聊天与记忆

- 会话按人设隔离。
- 支持新建、查看历史、切换继续。
- 设置内可查看全部过往聊天记录。

## 8. 提醒系统

- 创建：AI 从聊天提取结构化提醒；设置内手动创建。
- 类型：一次性、重复（每天/每周/每月）。
- 触发：应用运行中按人设语气弹气泡。
- 关闭期间到期：下次打开询问补提醒或标过期。
- 状态流转：未完成 → 完成；未完成且已过触发时间 → 已过期。

## 9. 天气与定位

- 定位：Windows 系统定位（需处理系统位置权限，失败时提示）。
- 天气：Open-Meteo 为主，和风天气免费版兜底。
- 时间/地点/天气在相关时注入 AI 上下文。

## 10. 里程碑建议

1. 桌面壳与透明置顶可拖动窗口、托盘。
2. 设置页：提供商、人设、时间参数。
3. AI 引擎与流式聊天、表情库生成。
4. 宠物状态机与活动。
5. 聊天会话持久化与历史查看。
6. 提醒系统。
7. 天气与定位。
