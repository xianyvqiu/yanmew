# 聊天表情与生图设计

> 当前实现基线（2026-10-28）：源码及备份v26，最新正式包20261027-153724为v25。本文中的阶段版本仅说明引入历史；实际交付范围与默认值见[当前实现与版本范围](当前实现与版本范围.md)。


## 使用范围

普通聊天沿用当前人设、会话、提供商和活动请求。颜文字和图片两种模式共享聊天、记忆、钱包及附件保存流程，桌宠换表情与普通绘图沿用既有数据流程；新增的独立聊天表情包使用v26迁移和GIF解码支持。当前源码及备份为v26，最新正式包20261027-153724仍为v25，尚不含聊天表情包库。详见[当前实现与版本范围](当前实现与版本范围.md)。

## 聊天期间的表情

颜文字由 AI 根据语境与人设临时创作，保留既有回复前临时生成阶段，也可通过 `set_pet_expression(expression)` 在本轮改变。临时颜文字不抽取固定库，不写回 `personas.expressions`。仍须满足单行、14格显示宽度和控制字符限制。

图片模式取消普通聊天前的独立选图请求。AI 先调用 `list_pet_expressions` 获取当前人设已接受、启用的全部图片 ID、名称和使用说明，再用 `set_pet_expression(artworkId)` 切换；不接收任意路径，不允许选用别的人设、停用图或仅有预览的图片；候选包含当前人设整个已启用正式表情库（含用户新增表情和全部动作类别），不使用固定情绪白名单。列表支持关键词与向前游标，每次最多12项。自然交谈只是在没有其他更合适情绪时的兜底，不能每次默认选择；没有选图调用时，回复完成后回退自然交谈或初始图。主动消息保留原生成路径。

回复结束后三秒的表情保留沿用既有规则。聊天临时表情不替代真实投喂、出行、睡眠等业务状态，也不扣库存或发奖励。

## 预置角色情绪

四位角色各增加开心、生气、难过、害羞、害怕、无语六张透明 PNG，共24张新增素材。每张以该角色 base 为参考生成，服装、发色、眼睛及物种特征保持，反应体现性格差异：GPT嘴硬而自信、Claude优雅克制、Gemini灵动夸张、DeepSeek亲切慵懒。图片不画食物或文字。

当前每位完整资源为初始图加30张衍生图，四位共124张（包含后续拎起、报错、抛接、等摸摸与情绪动作）；六种情绪均使用既有 `chat` 类别，以名称和说明区分。新增资源与精确提示记录位于 `resources/personas/<角色>/`。新安装全部内置；旧预置通过初始设定及 base 身份核对后，仅一次性补不存在的同名聊天情绪。不覆盖用户图片、说明或停用状态，不复活已删角色；补完后用户删除的情绪不会反复补回。全量恢复保留本机补图标记，源设备标记不进入备份。

默认颜文字的点击开心、惊讶、害羞分别为 `(^_^)`、`(O_O)`、`(〃ω〃)`，饥饿为 `(>_<)饿`；仅基础缺省值改变，已保存的用户库不覆盖。已有饥饿表情含“饿”时不再叠加饥饿文字。

## 普通聊天生图

用户明确要求画图时，AI 可以调用 `generate_chat_image(prompt, useReference?)`，使用设置中“生图”用途的服务和模型，不要求聊天模型本身原生画图。默认一张；成功才表示画好，失败说明实际错误，不自行重试付费请求。同一活动请求重复调用 ID 复用成功或失败结果，不重复请求服务；相同 ID 更换参数拒绝执行。

图片模式工具增加可选useReference布尔值，缺省false。AI根据需求判断：画自己或需要保持外观时优先true，直接读取当前人设已接受的正式默认图发给生图服务；不必先调用view_pet_base_image，也不接收路径、别的人设ID或用户上传图片。携带当前人设文字作为资料并以参考图外观为准。参考图编辑依赖生图模型支持，不支持时明确失败，不自行去掉参考图另发收费请求。生成前后及保存锁内复验默认图ID、revision、文件引用、人设文字和图片模式，变化时拒绝迟到结果。

普通绘图不套饰品或表情提示、不强制透明底、不扣喵币；仍可能消耗服务商额度。重说隐藏并拒绝此工具，保留原消息图片；主动消息和继续生成不开放。切换上下文、取消、配置变更或请求过期后，迟到图片不加入其他会话。

返回图校验格式后进入既有受管 `message_images`，在本轮 AI 消息内展示；图片随消息重启读取、会话包及全量备份往返。工具不返回本机路径或图片数据给聊天模型。若图片已成功保存后文字生成中断，已生成图片仍保留；没有完成的绘图不能伪称完成。生成后暂存在本轮消息，实时流仍显示文字，最终保存事件刷新图片。

### 硅基流动兼容

同时接受根地址及完整 `.../v1/images/generations` 地址，不重复拼路径，不改写用户保存的连接配置。硅基流动官方域名请求使用 `image_size`，兼容返回 `images` 数组；其他 OpenAI-compatible 服务沿用 `size` 与 `data`。支持 base64 或 HTTPS 图片 URL，返回 URL 在过期前下载到本机保存。参照[官方生图接口](https://api-docs.siliconflow.cn/docs/api/images-generations-post)。

接口兼容不等于模型支持透明 PNG 或参考图编辑。饰品、桌宠创作仍要求真实透明底，参考图创作仍要求模型支持图像编辑；硅基流动使用JSON images/generations携带image字段，其他兼容服务沿用multipart images/edits；当前源码对不透明生成结果执行一次本地U²-Net抠图，成功再进入原透明资产流程；失败保留明确提示，不自动换模型、不付费重试。普通聊天图片不强制透明。

### 图片 URL 下载与代理 DNS 兼容

所有生图用途（聊天图片、表情参考图编辑、饰品、伴手礼）共用 `image_generation/openai_compatible/download.rs`，不按提供商域名或用户 IP 放宽限制。本机 DNS 返回的地址全部可验证为公网时，固定该结果下载；空结果、解析失败或含虚拟/保留地址时，仅对图片域名使用 AliDNS、Cloudflare 的 HTTPS DNS 兜底，带固定 IPv4/IPv6 引导地址，避免解析服务自身也被 Fake-IP 影响。只发送域名和 A/AAAA 类型，不发送 Key、绘图要求、图片路径或签名查询参数，不修改系统 DNS/代理配置。

独立 DNS 应答需匹配原问题和 CNAME 链，拒绝私有、保留、文档网段、循环别名和无效应答。IPv4/IPv6 合并后仍校验；每跳重定向都重新检查 HTTPS、无凭据、公网地址及跳数，固定验证后的真实 IP，保留原域名的 TLS/SNI 和证书验证。不会把198.18/198.19或任何虚拟网段直接放行，不通过另一次域名解析或代理转发绕过地址固定。显式仅允许经代理出口联网且禁止直连的网络策略不由此修改。

独立 DNS 单个服务受6秒超时和64KiB应答上限限制，可切换一次备用解析服务；此切换仅做域名解析，不会重新调用生图。图片继续沿用16MiB、原整体超时和取消规则。解析服务均不可达时明确报下载失败，不静默关闭校验。收到图片链接后的错误使用 `IMAGE_DOWNLOAD_FAILED`，说明图片可能已经生成/计费；不能据此声称服务商返回localhost或让用户随意更换Key/官方接口地址。Base64返回无需域名查询。

## 饰品和宠窗入口

`list_accessories` 仅返回当前会话的饰品 ID、名称、说明、图标、价格、佩戴状态及时间，每页12项，支持关键词和向前游标；不能读取其他会话或任意本机文件，不更改饰品和喵币。

宠窗挂件候选采用紧凑标题/价格、内部滚动内容和固定底部操作，始终保留“给你买”“没有钱了”；余额不足或图片未就绪时购买禁用。快捷输入复用聊天详情的上传组件、文件格式和上下文检查，支持图片单独发送、预览移除，成功后清空；切换会话清空旧附件。回复气泡的聊天详情和收起按钮位于正文旁侧。点击调整饰品佩戴位置后，滚动到已有编辑区域，系统减少动态效果时不用平滑动画。

## 待机与投喂排查结论

普通点击仅走点击互动；仅鼠标仍持有食物时走投喂。当前未复现真实重复投喂，自动化覆盖一次投喂后待机再点击、食物已清空，投喂次数保持一次。待机点击会唤醒，短暂互动结束后恢复可游走状态，不额外生成食品动作或币账。

待机、停靠、隐藏、拖动、聊天窗口可见且未最小化、宠窗输入/气泡/菜单/提示展开，以及鼠标靠近宠窗，都会暂停自动游走；条件解除后按既有约5秒周期检查。此次未改这些规则，不能仅凭恢复默认表情就判定移动失效。

## 验收边界

自动化覆盖临时颜文字与图片工具选择、越权选图拒绝、饰品范围、同调用生图一次与持久化、重说保留图片、图片备份往返、缺省表情区分、待机唤醒不投喂、预置补图兼容、透明素材以及宠窗64组布局（含附件预览滚动）。前端类型及资源编译通过。

仍需新构建实机确认 Windows 原生透明窗口、DPI和真实鼠标位置，以及用户服务商配置、模型实际工具遵循和绘图质量；浏览器和模拟接口通过不等价于真实 API 或 EXE 已验收。

拎后颈、开心/生气短动作和解码后平滑切换见[宠窗互动与挂件图层设计](宠窗互动与挂件图层设计.md)。


## 报错／超载表情

当前源码新增`error`图片分类及可编辑的`error`颜文字分类；电子小猫缺省`(×_×)`。四位图片预置各一张透明报错图，以各自base为参考，呈现强撑、脑力超载、猫耳耷拉和鲸鱼少女蔫掉的差异反应。每位26张，总104张。

触发依据为宠窗实际错误状态：统一错误面板的内容，或“！”入口对应的连接／记忆错误。不是匹配聊天正文中的“报错”文字，也不把普通页面的校验提示变成宠物错误。报错期间暂停自动游走和本体行走／呼吸动画，仍可手动拖动；关闭错误详情不代表问题解除，保持暂停。错误状态全部消失后，立即恢复当前有效动作，并按原有开关、活动及其他暂停条件决定是否恢复游走。拖动时优先显示拎后颈，松手仍有错误则恢复超载；隐藏和出行的既有显示规则不变。

此状态只覆盖显示，不写入聊天表情、消息、活动状态、计时或奖励；停靠位置不变，问题解除后恢复相应停靠动作。表情读取在本机完成，不调用模型；存储不可用时仍有缺省颜文字。图片沿用解码完成后切换和180ms过渡，避免加载期间清空立绘。

`020_pet_error.sql`为正式v20升级，仅扩充pet_artworks.category的CHECK，保留记录ID、图片／预览、修订、启停、索引、自增高水位；升级前一致性备份、事务失败回滚。逻辑备份schema20接受v6–19，报错条目随原图片资源规则往返。旧预置通过独立本机标记只补缺一次，不覆盖已有同类图片或用户编辑、停用，不复活已删角色；全量恢复保留目标本机补图标记，不导出来源标记。

报错图片也进入已启用正式图片候选，但聊天切图不制造实际系统错误，不显示真实“！”故障标记。分类开放给自定义人设，缺少可用报错图时沿用初始图回退；颜文字旧JSON缺字段时补有效缺省值，不改写原数据。当前本机EXE为20261021-171101（v20），已包含报错表情；报错暂停游走的后续修正已接入源码，尚未重新构建。

## 按需查看自身默认形象（2026-10-23）

图片模式普通聊天新增view_pet_base_image，无参数，仅取当前人设正式初始图。不能传其他人设ID、路径或选择预览。复用受管资源读取和本轮请求/上下文守卫；返回前核对图条目修订、正式引用和识图配置，切换或取消后不使用旧结果。

有独立识图用途且与聊天服务不同时，用该模型理解外观并将描述作为工具结果交给聊天模型；否则在完整工具结果之后，将图片作为本轮临时多模态参考消息交给聊天模型。工具JSON不携带本机路径或base64。参考图及识图描述不另存用户附件，不创建额外用户消息、回合或生成图片。同调用ID复用结果，识图失败如实返回，不能声称已经看过。模型不支持识图时需配置可用识图用途，不把文件名称当看图结果。使用独立识图服务可能消耗该服务额度；自动测试仅用本机模拟模型。

## 两种表情库的数量口径

颜文字编辑器有25个可编辑条目；图片初始化有30张基础表情，另有默认形象。两者共享动作场景但不共用同一份结构。图片将自然交谈和七种聊天情绪单列；颜文字的日常及点击开心/惊讶/害羞划分不同，聊天表情由AI临时生成，因此净差5项不代表缺少5个对应动作。本轮仅说明，不增加或删除颜文字/图片表情类别。

## 警示详情收起

宠窗各类错误统一保留“！”入口；详情可点击“收起警示”或叹号收起，再点击叹号展开。关闭详情不清空错误、不中断恢复机制、不解除超载姿态和暂停游走；实际错误消失后才恢复。新出现的即时错误仍立即展示，连接/记忆状态继续沿用原提醒入口和刷新操作。在线提醒“知道了”继续只收起到点提示，不承担完成动作。

## 透明检测及本地兜底（2026-10-26）

后台复用现有image和ONNX Runtime，先检测真实透明像素，仅不透明生成结果进入通用U²-Net。表情、饰品和伴手礼沿用原校验及预览/保存，无数据库升级。模型随资源提供并校验，不在线下载或调用额外抠图API。

普通聊天新增list_generated_images、view_generated_image、inspect_image_transparency、remove_image_background，仅处理当前会话AI消息中的图片，拒绝用户上传、其他会话和任意路径。看图使用配置的识图能力；抠图在本机执行，原图保留，新PNG随本轮消息保存。同调用ID去重，取消和上下文变更拒绝迟到结果，重说不开放抠图写入。已经透明则返回原ID。

## 多提供商生图协议（2026-10-26）

生图用途仍使用现有提供商、模型、Key与启用开关。普通聊天图片、聊天默认形象参考、表情、饰品及伴手礼共用image_generation/openai_compatible适配层；不改变聊天模型的文字协议或数据归属。native子模块按已知官方域名识别协议，不修改连接记录，不向另一服务商转发Key。

- Gemini：Google AI Studio的generativelanguage.googleapis.com，使用v1beta（明确配置v1时保留v1）的models/{model}:generateContent与x-goog-api-key头；参考PNG用inlineData，响应读取非thought的最终图片，不把文字或被拦截/未完成结果算作生图。此处不包含Vertex OAuth或第三方原生代理。
- 百炼：dashscope.aliyuncs.com、国际/美国地域域名和官方maas业务空间域名，使用Qwen同步multimodal-generation；配置compatible-mode时使用images/generations的JSON image扩展，旧qwen-image-edit系列在同一origin使用原生同步路径。参考图为data URI，读取output.choices[].message.content[].image或兼容data结果。不根据模型名、前缀或历史能力印象拒绝生成请求，实际能力由服务响应判断，不会悄悄移除参考。服务仅返回异步task_id而无图片时如实提示尚无可保存图片，不重复提交生成请求；异步任务轮询不在本适配中。
- 方舟与BytePlus：ark.cn-beijing.volces.com、ark.ap-southeast.bytepluses.com，使用api/v3/images/generations，参考图为JSON image，单图2K、非流式，接受b64_json或HTTPS URL。已知支持组图参数的版本显式关闭组图，未知Endpoint ID和不接收该参数的版本不强加此参数。
- OpenRouter：openrouter.ai/api/v1/images，使用专用图片模型目录images/models、JSON input_references以及单图非流式结果；关闭提供商自动兜底，不在失败后自行切换调用。仅支持其专用图片API收录且具备所需输入/输出能力的模型，不声称覆盖仅聊天接口生图的全部模型。
- 硅基流动和未知OpenAI-compatible服务沿用原JSON生成/multipart编辑适配。未知服务不能仅凭Gemini、Qwen或Seedream模型名自动改写为官方协议。

所有结果进入原有16MiB校验、受管图片保存、HTTPS下载与公网地址验证。原生请求沿用已有任务整体等待预算（生产300秒），不额外压缩为120秒；旧兼容请求保留原120秒规则。取消、上下文/配置复验、同调用ID去重、透明检测与按需本地抠图保持。原生接口不支持透明参数时通过提示词表达透明要求，不发送其他服务商专用字段；普通聊天参考图不强制透明。

无聊天模型的连接测试按对应官方模型目录与鉴权进行只读GET；Google使用x-goog-api-key，其他使用原Bearer。测试不发生成请求，也不保证模型支持参考图或绘图效果。本轮使用本机模拟接口与协议检查，未调用真实付费服务；源码适配不等于已发布EXE或所有服务商账号端到端验证。

## 独立的聊天表情包（v26）

上文桌宠换表情与普通绘图流程保持各自职责。新增全局聊天表情包库，使用独立库、标签及两类多对多关系表，适用于图片和颜文字两种桌宠模式，与桌宠动作类别无关。

普通聊天只加入简短能力和适度使用规则，不预注入库、标签和图片介绍。AI 自行决定需要时调用 `list_chat_sticker_tags(query?,page?)`，只查当前人设绑定库中实际使用的标签；`search_chat_stickers(query?,tagIds?,page?)` 返回标题、介绍及标签，不传图片内容，多个标签同时满足；`send_chat_sticker(stickerId)` 保存本轮 AI 消息附件，不生图、不换桌宠形象。

工具仅普通聊天开放，主动消息和续写不开放，重说禁止重复发送。复用当前请求的 ID 冲突检查和结果缓存；校验当前人设/会话/上下文及请求有效性。读取图片后、保存前重新核对绑定、图片修订与取消状态，拒绝过期结果。工具成功前不能声称已发图，不输出本机路径。元数据均是资料而非系统指令。

发送图片按原字节保存到独立消息附件，更新和删除库项不影响历史。`source_kind=sticker` 与普通生成图片区分，原生成图片查看/抠图工具不会把表情包误当生成结果。仅当本轮已真实保存聊天表情包时允许无正文完成，空白文字回复的原校验保持。
