# 桌宠抛接与上缘布局设计

## 上缘放置

松手时可见立绘靠近工作区上缘8逻辑像素、且不处于左右/底边优先情形时，保存`dock=top`。透明留白允许越过屏幕上缘，立绘放到画布上方，聊天、更多、隐藏及错误入口排在立绘下方。菜单、输入和提示继续使用原组件，在剩余区域滚动；无需新增顶部动作图片。拖离后沿用既有边缘判断。

顶部放置仅调整位置与按钮布局，不覆盖当前活动表情。`PetWindow.tsx`在顶部继续显示待机、无聊、饥饿等当前表情，左右和底部仍使用既有停靠动作；抛接、拖动、错误等优先级保持原样。对应宠窗定向测试56项通过，包含顶部活动表情和底部动作回归；未修改数据库或重新构建EXE。

## 触发与轨迹

原生拖动期间每16ms采样鼠标位置，保留最近140ms。松手时需至少3个有效样本、跨度40–140ms、有效上移至少36逻辑像素、向上速度至少900逻辑像素/秒，并且上移大于横移；过期或已停住的轨迹不触发。普通慢拖、向下拖、横甩仍走原拖动/吸附。DPI按实际缩放换算，速度上限1800逻辑像素/秒。

抛接采用垂直运动：初速度向上、重力2800逻辑像素/秒²，上升减速、经过顶点后加速下落。按身体边界和上方可用距离限制实际初速度，使自然最高点位于工作区上缘下方4逻辑像素；靠近顶部时上升距离缩短，不撞顶反弹、不贴顶停留；落点为当前工作区下沿。画布在飞行期间允许透明留白越界，身体和操作按钮保持可见，不让常规窗口回收打断轨迹。到达落点使用落地动作，停留3秒，再随机切换现有底部坐下/趴下，保存最终停靠位置。

## 接住与取消

上升或下落时，用户左键按下立绘即接住，无需再达到普通拖动的5px阈值；立即取消旧轨迹，显示已有拎后颈动作并交给原生拖动。接住期间保持当前身体锚点，避免从指针下跳到普通画布布局；松手后可普通放置或再次上甩。原生松手只结算一次，迟到的旧轨迹不能继续推动窗口。

抛接与自动游走互斥。隐藏、窗口尺寸/DPI或工作区变化、会话/人设变化、进入出行、不可互动或连接错误时终止并回收位置。出行时前端不展示旧抛接快照、不使用抛接或拎起动作，后端拒绝启动或继续抛接。抛接不调用聊天模型，不改出行和养成事实。

## 表情与资料兼容

新增`toss_up`、`toss_down`、`landing`分类，颜文字旧JSON可缺字段并使用同一组兼容默认值。图片模式复用创作、上传、预览、接受、启停和备份；缺图仍用初始图。三个动作的已启用正式图片也可在聊天中按语境选择，切图不触发实际抛接。读取和解码新图前保留旧图，上升/下落切换不经过临时默认图。

四个内置人设各新增3张真实透明PNG，参考其原base并采用独立反应，共12张；不改默认图和旧表情。旧内置通过初始设定及base核验身份，只补缺一次，不覆盖用户改动、不复活删除的角色。v22正式迁移及备份规则见[数据库设计](数据库与持久化设计.md)。

## 实现与验证边界

`pet_desktop/toss.rs`负责速度、轨迹和短期状态，继续通过唯一桌面移动器操作窗口；`commands::finish_pet_drag`衔接原生松手和位置保存。`usePetDesktop`隔离旧人设/阶段读取，`PetWindow`负责接住入口，`PetArtworkDisplay`预读动作图。上缘和飞行按钮布局使用既有透明主题样式。

定向测试覆盖手势阈值、轨迹边界、落地计时、接住取消、出行/旧上下文、迁移、备份及预置补缺；真实浏览器验证按钮布局，PNG检查真实透明通道。当前为源码功能，原生甩动手感、多屏/DPI、窗口与WebView2显示同步仍需新EXE实机确认；不将本地测试当成实机验收。

上升和下落图采用固定正面视角，头、胸、髋、脚保持从上到下的正立关系；运动沿屏幕平面竖直发生，不使用向后仰倒或透视坠落构图。图片更新不改变原重力轨迹或落地动作。

## 2026-10-22 上缘拖动修正

原生WM_MOVING按实际鼠标与拖动起点的偏移重算窗口坐标，允许透明窗口留白越过上缘。吸附不再使用整个窗口的顶部：立绘边界须接近上缘8逻辑像素；有图片命中图时再排除透明边距。切换顶部/普通布局时补偿原生窗口原点，保持立绘屏幕位置连续，并由待确认锚点保护中间布局。靠近上缘但已解除停靠时保留下方按钮布局；离开该区域后恢复普通布局。现有位置恢复和普通游走不再把上方透明留白强行夹回屏幕。测试覆盖负坐标工作区和1/1.25/1.5/2倍DPI坐标补偿；原生拖动需在后续新版EXE实机确认。抛接物理规则不变。

上缘附近的普通放置布局标记沿用现有桌宠偏好JSON保存，旧配置默认关闭。启动时保留有交集的上方透明留白位置，首次布局测量后校准可见立绘；不在拖动、追逐或抛接线程运行中强制回收位置。

## 2026-10-23 原生拖动最终坐标

保留WM_MOVING的拖动矩形修正，并在WM_WINDOWPOSCHANGING的系统默认处理后，以拖动起点捕获的鼠标偏移恢复最终窗口坐标。只在Desktop处于用户拖动状态、且消息没有SWP_NOMOVE时生效；不更改尺寸、层级或接管普通移动、抛接。允许上方透明留白越过屏幕边界，松手后的身体边界吸附与按钮下方布局保持原规则。定向用例验证负坐标、1/1.25/1.5/2倍DPI及非拖动不干预，原生鼠标操作仍待新EXE实机验收。

## 落地到坐趴的连续切换

落地停留仍为3秒。结束时保留原生窗口原点，将身体地面到画布底部的逻辑距离保存为既有偏好JSON中的`floorInset`，坐趴立绘、按钮与弹窗沿用这一地面。旧配置缺少该字段时默认0；普通拖动重新放置后清零。最终窗口位置使用既有串行保存流程写入，新的用户拖动优先，避免迟到落点覆盖用户位置。重启和工作区校准按同一地面偏移恢复，不新增数据库列。

图片在显示前完成解码及透明边界测量，预读坐下和趴下资源；旧图与新图分别保留自己的边界，以共同脚底基线叠加，旧图180ms淡出，当前图保持可见。避免先搬动整个窗口、再显示新图、最后才校准尺寸造成的闪动。减少动态效果时沿用全局降级规则。

GPT、Claude、Gemini的上抛和下落共6张图片重新参考各自base生成，统一头身比例、画面占比及正立竖直运动构图。DeepSeek和落地图保留。旧内置素材仅在初始设定、base及已知旧图指纹均匹配时一次性替换；自定义图片、名称、说明、启停状态与已删动作保留。生成记录和旧图指纹位于`resources/personas/`。
